# DIY卡面渲染提示词 v3.0(2026-11-19)

> 用途:出卡轨(AI会话)输入提示词。照抄以下规范,不得改写数值/时点/角标。

## 输入(设计轨输出)
- 角色名/称号/UA机制名/五风格(名/四数值/效果句)/专属(名/四数值/效果)/终结技×2(名/四数值/效果/αβ面)/角标分配/街霸6锚点

## 色彩层(照抄,逐句执行)
- ⟨绿粗⟩**开始,条件:**⟨/⟩ / ⟨红粗⟩**命中,条件:**⟨/⟩ / ⟨蓝粗⟩**前置:**⟨/⟩**后置:**⟨/⟩ / ⟨黑粗⟩**展示:**⟨/⟩**循环:**⟨/⟩**初始设置**⟨/⟩
- ***+1速度*** ***+2威力*** *1假面*(粗斜体) / **护甲2** **削命2**(黑粗) / *(斜体括号)*
- ⟨灰底⟩⟨紫粗⟩**每当**⟨/⟩…⟨/⟩ / ⟨橙粗米底⟩**【对手】投注:**⟨/⟩
- 机制关键词全卡加粗;效果前◆来源标注(随来源风格)

## 角标(照抄,跨角色统一)
- 风格=红◆斜方形/橙⬟五边形/黄⬡六边形/绿▼倒三角(勿与▲混淆)/蓝●圆形,同一角色五色各一次
- 专属=☾灰月;变招=★紫星;终结=✳白α正面/✴灰β背面(双角标一致);晕免=🛡印韧性栏;弃牌堆=角标:N;双面=α正β反

## 数值记法
- 四数值=距/力/速/韧;距离连字符1-3;速度含▲;X威力斜体X;无韧填0;晕免🛡

## 排版
- 风格=大色框(底色同角标色)+牌名+四数值+效果(着色)+左上角色角标+右下数字
- 专属=黑边框+☾左上;变招=★+双面;终结=完整框+双角标+四数值+双面;提示卡=标题+角标大图+黄框数值+斜体效果
- 字体:牌名宋体大字;效果黑体;风味小宋

## 出图提示词模板
"为「{角色}」的{风格}出卡面图:大色框{色}(角标同款色)+顶部角色名+中央机制插画+底部四数值(距/力/速/韧)+左上{符号}角标+右下{N}。效果文本着色:开始绿粗/命中红粗/展示黑粗/前后置蓝粗/循环黑粗/+X粗斜体/护甲削命黑粗/括号斜体。风格名二字,效果句官方范式(时点,条件:效果)。禁止改数值/时点/角标。"

## 校验(出图后)
- [ ] 五色各一不重复 [ ] 角标形状对 [ ] 数值四栏 [ ] 时点着色正确 [ ] 粗斜体规范 [ ] αβ面正确
