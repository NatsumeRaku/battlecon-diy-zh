**全角色统一·官方五色五形对(2026-11-20二次修订核心)**:
- 规则:风格=黄⬡/绿▼/橙⬟/红◆/蓝●;专属=☾灰月;变招=★紫星;终结=✴✳八芒星;晕免=🛡;弃牌堆=角标:N;双面=α/β。**跨角色统一,同一角色5风格五色各用一次**(绝不重复)。五形=菱形(红)/五边形(橙)/六边形(黄)/三角形(绿)/圆形(蓝),即"红黄绿橙蓝"五色对五形。
- **禁止任何功能色编码**——原v1.0"DIY专属形+功能色"全部作废;角标只有"牌类"一个维度(官方用法)。
- 官方十二套排版色:风格5色 + 专属灰 + 变招紫 + 终结(白α/灰β双色) + 提示卡黄 = 九色板。

## 二、卡面排版约定(与官方一致)

**风格牌**:大色框(底色)+ 牌名 + 距离/威力/速度/韧性四数值 + 效果文本(色彩层着色) + 左上角色角标 + 右下数字(如有)。
**专属招式**:黑边框卡 + ☾灰月角标(左上) + 四数值。
**变招切换卡**:★紫五角星角标 + 两面(变身前/变身后状态)。
**终结技**:完整框(大边框独立框) + 双角标(左上+右上,两枚一致:✳白α或✴灰β) + 四数值;双面卡(α正面/β背面),翻面规则见finisher-switch-protocol。
**参考卡/提示卡**:左上大图标 + 右上黄色数值框 + 效果说明(*斜体*) + 来源角标;背面=角色立绘。
**UA卡**:机制名 + 初始设置 + 规则说明;机制名上卡,与官方一致。
**数值写法**:①四数值=距/力/速/韧;②距离区间用连字符(1-3),不用波浪号;③速度含▲先攻标记;④眩晕免疫=🛡印在韧性栏;⑤X威力/X速度用斜体X。

## 四、引用符号说明

角标=官方印刷识别码;书写时用"符号+形状名"并列(如"红◆斜方形"),便于跨字体环境识别;近似符仅用于速查:⬟=五边形近似、⬡=六边形近似、▼=倒三角(官方印刷为实心倒三角,勿与▲先攻混淆)、✴✳=八芒星、☾=灰月(月牙)、🛡=盾。

## 五、风格名与专属机制名(角色卡面)

- 风格名全两字(E级6),同角色内不撞词根
- 专属机制名与风格名体系分开;机制名短(2-4字)且风味化
- 双面终结技两面各一名,α/β各标
