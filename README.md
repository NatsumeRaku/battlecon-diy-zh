## 数据规格

### JSON字段规范
```json
{
  "卡类": "风格|专属招式|终结技|特技|角色",
  "名称": "",
  "角色": "",
  "系列": "",
  "角标": "<字符串标签>",
  "数值": {"距离":"", "威力":"", "速度":"", "韧性":0},
  "效果": [{"时点":"", "条件":"", "效果":""}],
  "来源": "官方实卡2026-11|DIY-工坊vX"
}
```

- 角色卡额外字段：`英文`、`称号`、`类型`、`难度`、`机制名`、`机制概述`、`角标分配`、`卡牌清单`
- 终结技额外字段：`数值`（含α/β面）、`效果`（含α/β面）
- **已删除**：优先级、录入方式、备注、last_updated、版本、变更记录

### 来源标注规则
- `官方实卡2026-11(用户拍摄)` — 毁灭篇/战争篇实卡
- `DIY-工坊vX(YYYY-MM-DD)` — DIY角色设计文档
- `待核验` — 未实卡核对
- 涉裁定信息追加在`来源`字段（见下方裁定记录）
