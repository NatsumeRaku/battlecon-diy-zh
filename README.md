# 战链DIY（battlecon-diy-zh）

战链（BattleCON）DIY 项目资料库 —— 项目记忆库全量备份 + 工程成品文档。

## 目录结构

- `areas/` —— 进行中的工程（毁灭篇实卡校正室、β Duel 全角色配招）
- `convention/` —— 工程公约与裁定协议（最高准则、覆盖规则、竞技场规则精读、变招/终结技协议、状态机模拟协议、卡面印刷规范等）
- `topic/` —— 主题资料库（钦定术语表、v4.2 规则书载录、角色名册、通用招式库、特殊玩法、DIY 角色稿、模拟战报与引擎结果等）
- `docs/` —— 输出成品（启动简报、提示词、卡面规范、模式指南等）

## 备份说明

- 基线日期：2026-11-22
- 记忆库文件（areas/convention/topic）源自项目记忆库实时读取，逐字照录（含 YAML 头）
- 唯一编辑：convention/source-precedence.md 末尾的写通道探针注释按原作者指示删除
- 推送方式：GitHub MCP 分批推送，批次数以提交记录为准
