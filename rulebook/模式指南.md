# 超凡与无限招式

（图：超凡招式牌一组）

你可以使用“超凡”和“无限”招式替代规则书中的“超级”和“终极”规则，以获得更为接近首领战的多人游戏体验。

若想使用超凡与无限招式，你不会获得超级/终极参考牌上列出的强化（包括额外的能量和额外的超载板块），而是将你的标准招式替换为超凡或无限招式（单人斗士依然拥有增加过的总生命）。

超凡招式建议由1对2对决中的单人斗士使用。

无限招式建议由1对3对决中的单人斗士使用。

# 竞技场

（图：信用行者竞技场总部）

竞技场是一种特殊的变体玩法，你可以使用它改变游戏规则，并将游戏故事中的特定场景变为现实。只需选择一个竞技场，在游戏开始时将它设置到游戏中，像使用其他生效卡牌一样执行它的触发效果。

竞技场是为1对1对决而设计的，最好不要与多人模式规则共同使用。

# 竞技场的初始设置

竞技场可能会有初始设置步骤。请在对决开始时，在所有其他玩家之前执行这些步骤。

# 竞技场的触发效果

竞技场可能会拥有触发或被动效果。这些效果的使用方式与普通的触发效果一样，并且会影响到双方斗士。如果竞技场和斗士拥有相同时间点的触发，那么总是先执行竞技场的触发效果，然后再执行其他斗士的触发效果。

# “全员”修正

许多竞技场具有“全员”修正。“全员”触发被视为属于双方斗士，如同它被印刷在双方斗士的特技牌上一样。

例如：“【全员】，命中：推动2”，每当一方斗士命中另一方斗士时，就会触发推动2的效果。

# 能量计数物

许多竞技场会在初始设置和特殊效果中使用能量计数物。除非另有说明，否则这些能量计数物总是来自游戏盒，而不是来自能量计数物堆。

# 首领剧本

首领剧本是多名玩家组队共同对抗由另一名玩家控制的强大首领的一种合作游戏模式。首领可以同时对战2名、3名或4名玩家。

首领有自己的套件，他们玩起来也和斗士有着很大的不同。

本节会详细介绍所有首领共同使用的核心首领规则。任何其他差异或特殊规则都会在首领的特技牌上列出。

# 架势与套路

（图：就绪 烈爪）

首领使用的卡牌被称作架势和套路，而不是风格和招式。架势牌上有一组速度和韧性数值，而非风格牌上的速度和韧性修正值。类似的，套路牌上只有距离和威力数值。这意味着一个首领的速度和韧性完全由他的架势牌确定。

需要注意的是，首领的卡牌不是风格与招式，而是架势和套路。因此，它们会无视任何涉及风格和招式的效果。不过，每当首领无视这样一个效果时，他们就会受到削命1。在考虑首领的攻击时请牢记这一点。另外需要注意的是，架势和套路仍然是“攻击组合”，会被涉及“攻击组合”的效果所影响。

# 初始设置

首领模式在9格战场中进行游戏。首先由首领将自己的立像放置在战场上的任意一格。然后再由敌方斗士们按照他们选择的顺序在战场的任意格中放置立像。

在游戏开始时，每存在一名敌方斗士，首领就拥有25生命。然后，首领根据敌方斗士的数量，将未包含在其套件内的卡牌移除。

与普通斗士一样，首领也有2个弃牌堆。不过在初始设置时，每存在一名敌方斗士，首领就往每个弃牌堆中放置1张套路。这些弃牌堆会像普通斗士的弃牌堆一样进行循环。

在这之后，首领必须激活一些由他的特技牌决定的架势（通常取决于敌方斗士的数量）。这些架势会在战场中保持面朝上，所有人可以看到。其余架势在首领的手中。

（图：伯尔曼架势组——充能、燃烧、熊爪、功亏一篑、谨慎、一式）

在这局游戏中存在两名敌方斗士，伯尔曼会在他的每个弃牌堆中各放置2张套路，然后根据他的特技牌来激活3张架势（敌方数量+1）。

# 设置阶段

首领必须在所有敌方斗士设置好攻击之后再设置自己的攻击。首领不会设置攻击组合，而是可以从手中向他的任意数量的生效架势牌上各设置1张套路。这一点再加上首领架势上所显示的速度和韧性数值，意味着敌方斗士会拥有许多关于首领速度和韧性的信息。

# 首领的能量与投注

首领和普通斗士一样会生成能量。他在游戏开始时拥有2能量，在循环时获得1能量。若他只拥有7或更少的生命，也会获得额外的1能量（总共获得2能量）。

不过，首领不能像普通斗士一样获得通常的能量超载（+1威力、+2速度、+2韧性）。相反，首领拥有一套独特的投注选项，是由他的特技或架势牌提供的。当轮到首领进行投注时，他们可以使用这些投注效果中的任意一个，并移除所需的能量。

（框：限定投注：移除1能量来为本架势+2速度。）

# 展示与首领的攻击

在展示阶段，首领不会展示他的套路，而是继续让它们保持面朝下。这意味着敌方斗士将无法知道首领攻击的全部属性，因为他们只能看到首领面朝上的架势。

在用于进行攻击时，首领的每张生效的架势视为一名独立的斗士，共用首领的生命和立像。当按照速度顺序轮到一张架势时，首领展示这张架势附属的套路，并执行攻击。没有设置套路的架势不会执行攻击。因此，不会激活它们的任何前置、命中、伤害或后置效果。但是，开始、结束、当…时、每当、击破和被动效果依然正常执行。

当两张生效的架势拥有相同的速度时，由首领选择它们的执行顺序。

# 选择目标与进行攻击

在用于选择目标时，首领的每张生效的架势视为一名独立的斗士。如果效果或攻击需要以首领为目标，玩家就必须选择首领的一张架势作为目标。如果效果和攻击以一张架势作为目标，则不会影响到其他架势。

# 眩晕与击破

由于首领的每张生效的架势视为一名独立的斗士，因此每一张架势必须被单独眩晕。这意味着对首领的一张架势造成的伤害只会作用于这张架势的眩晕，不会影响其他架势的眩晕。

当一张架势被眩晕时，它就视为被击破。当这种情况发生，展示附属的套路（如果还未展示），如果这张架势没有“不可击破”，就执行这次攻击上所有正常的击破触发效果。被击破的攻击不会激活…【下接第6页】

# 群体攻击

许多首领拥有群体攻击。这些攻击会命中其攻击距离内的每名斗士，而不是只命中最近的一名斗士。群体攻击在卡牌上的距离后会印刷着一个菱形符号作为提示。群体攻击的距离仍然只计算首领的一个方向。它不会命中首领两侧的斗士。

（图：命中！命中！烈暴风 强压）

这个攻击可以命中浩动的任意一侧。由…无法命中塞萨尔，所以他选择向右侧攻击茹妮卡和乔尔。

# “每名”修正

有些首领的触发效果上会拥有“每名”修正。这种触发效果对每名相关的敌方斗士都激活一次。例如，“命中，每名：推动2”会把命中的每名斗士都推动2格。首领可以按任意顺序对目标执行这些效果。

# 生命、立像与消灭

无论哪张架势被作为目标或被攻击，影响生命或立像的效果和行动都会应用到首领的生命或立像上。这意味着无论攻击哪张架势，伤害会被应用到首领的总生命上；无论移动哪张架势，都会移动首领的立像。

有些效果也会直接影响首领的生命，例如“削命X”或“对手的生命在本回合不会减少到1以下”，无论哪张架势被作为目标，这些效果也都会应用在首领的总生命上。

最后，无论哪张架势被消灭（作为受到伤害或效果的结果），首领也都会被消灭。

## 第6页跨页（IMG_20261121_220054.jpg）

### 不可击破（接上页"被击破的攻击不会激活…"）

不可击破是出现在一些首领卡牌上的特殊关键词，它会给予首领一项非常强大的防御效果。在展示具有不可击破的卡牌之前，游戏照常进行。但只要拥有不可击破，这个攻击就不再处于眩晕状态，也不能被眩晕。在这种情况下，这个攻击的击破触发效果不会激活。

### 首领护甲

首领的某些卡牌上可能拥有护甲或产生护甲的效果。每当首领获得任何数量的护甲时，他改为获得同等数量的首领护甲。

首领护甲的功能与普通护甲非常相似，只有一项主要区别。首领护甲并非只应用于首领的一张架势上，而是所有的架势都能共享，必须先把首领护甲减少到0，才能使首领的任何架势开始受到伤害。

例如，如果架势A令首领获得护甲3，就会改为获得首领护甲3。现在，即使敌方斗士要以架势B作为目标，他们也必须先把首领护甲减少到0，才能让架势B开始受到伤害。

除此之外，首领护甲的功能和护甲完全一样。任何影响护甲的效果，都会以同样的方式影响首领护甲（"无视护甲"也会同样无视首领护甲）。如果一个效果需要检查首领的一个攻击有多少护甲，那么首领的每一个攻击的护甲数值都等于其剩余的首领护甲数值。继续前面的例子，当一个效果需要检查首领的护甲时，架势A和架势B都拥有3护甲。

（图：伯尔曼的延伸臂腕／戳刺／不息臂腕／侵掠如火等卡牌示意。卡图小字不清，不转录。）图注：首领护甲3!（左图）戳刺为右边的架势提供了+3威力和+3护甲。护甲3变成首领护甲3，并会保护两张架势。

### 强化、惩罚与其他效果

强化、惩罚和其他效果（例如奥塔维亚的"瞄准目标"这样的特有技能的指向性效果）单独应用于首领的每张架势。不过，有些效果可以将架势移出游戏。这种情况下，除非另有说明，否则应用于这张架势的强化、惩罚和其他效果会消失，并且不再应用。

### 闪避与回避攻击

许多回避攻击的效果会像针对普通斗士那样正常发挥作用。但一定要记住，首领的每张架势视为一名独立的斗士。

不过，"闪避"招式在这里会有一项特殊规则。闪避招式允许玩家在利用闪避的开始效果前进越过首领立像时，回避首领的所有攻击。这项特殊规则之所以存在，是因为闪避被指定的是"对手"，这在标准规则里意味着闪避玩家需要把首领的一张架势作为目标（因此接下来只能回避这一张架势的攻击）——但在首领模式下，闪避能够让玩家回避首领的所有攻击。

（图：就堵／侵掠如火等卡牌示意，卡图小字不清，不转录。）图注：（上图）梅尔乔拉的战术尝试检查伯尔曼的套路。由于伯尔曼的套路还没有展示，架势的威力为0，因此梅尔乔拉获得了额外的威力。

### 数值比较

有些效果可能需要玩家将一项数值与首领的数值进行比较。然而，大多数首领在激活前不会展示套路，因此他们的数值可能只是一项修正值（例如攻击只有一个+1～2距离）。在这种情况下，在比较数值时将其视为0（就像N/A和X数值一样）。

## 战斗探索地城（IMG_20261121_220200.jpg）

战斗探索是《战链》的一个单人/合作地城模式！你可以独自或与一群朋友一起探索，构建你的角色，并在途中对付各种怪物和首领。

### 游戏玩法

在冒险过程中，你将会穿过一系列房间，每个房间中会包含一组怪物。玩家从一个房间的入口格或相邻格开始，使用正常的《战链》规则进行战斗，直到所有斗士或所有怪物被击败为止。

你在每个房间中的表现往往会决定你可以选择哪一条路线前行。而在未特殊说明的情况下，你可以从多条路线中自由进行选择，但不能回到之前在地城中已经通过的房间。

有些房间中没有战斗，取而代之的是剧情叙述，你需要在这里做出决定才能继续前进。

在每个房间结束之后，玩家会保持自己的总生命不变。在所有其他方面，初始设置每个房间与在《战链》中开始一场新的对决是一样的。

### 团队地城

有些地城是多人团队地城。在这些地城中，每名玩家控制一名不同的斗士，按照正常的多人游戏规则进行游戏。如果一名斗士在这些地城中被击败，他会在下一层以剩余1生命的状态回到游戏中。

### 结伴地城

有些地城是结伴组队式地城。在这些地城中，一名玩家将控制多名斗士。在循环步骤中，你可以将团队中的一名斗士交换为另一名斗士。每名斗士都会保持他们自己的弃牌堆和总生命。能量则由地城中的所有友方斗士共享。

### 能量计数物堆

在地城中，没有限制游戏时长的能量计数物堆。取而代之的是，玩家会在每个回合结束时直接从游戏盒中拿取能量。

### 失败

当所有斗士都被击败时，玩家就失败了。在这种情况下，你可以重新尝试刚刚失败的楼层，以先前的总生命和资源再试一次。

### 怪物攻击

（图：标有1~6数字的怪物指示物）在每个回合中，将一组（6个）怪物指示物洗混，并给房间中的每只怪物分别面朝下分发一个指示物。在展示步骤中，展示这些指示物，指示物上的数字会决定在即将到来的回合中将会执行怪物的哪一种攻击。

### 怪物移动与做出决定

每当移动时，怪物会在保持目标位于其攻击距离内的前提下尽可能远地移动。这意味着它们会尝试尽可能远地移动，同时保持至少一名斗士在其攻击距离之内。

每当怪物需要做出任何其他类型的选择时，玩家需要为它们选择。如果你喜欢更大的挑战，那就一定要从怪物的角度出发，做出对怪物而言最好的决定。

### 投注

怪物一般来说无法进行投注。但是，如果一名斗士给予了怪物一个投注选项，最近的怪物将尝试最大限度地使用这个投注（只要在游戏中不是无意义的，并且对怪物来说是可能的）。

例如，怪物一旦接收到雷克森的诅咒和亚历克希安的骑士精神，就会立即使用它们。而只有当科拉拥有至少一个毒刺时，怪物才会尝试移除毒刺。

### 弃置卡牌

怪物不使用卡牌，所以它们无法弃置卡牌。取而代之的是，当怪物被迫弃置一张卡牌时，它们会面朝上弃置自己的一个指示物。这个指示物在下一个循环步骤（下一个回合，不是当前这个回合）结束之前不会回到它们的指示物堆中。

### 速度相等

如果出现速度相等的情况，玩家总是胜过怪物，无论在游戏中哪一方有更多团队成员。
