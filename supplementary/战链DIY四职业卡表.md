## 一、铁甲战士（The Ironclad）

**强攻型 / 中级** · 称号：燃血之壁 · v2.2（v2.1三补丁＋燃血3次/回合成环回调）

### 特殊能力：燃血之躯
- Setup：你拥有2枚血怒。消耗其余血怒。
- Ante，每回合至多3次：燃血1（你失去1点生命，获得1枚血怒；视为削命，不能降至1以下）【v2.2成环回调】。
- Ante：你每消耗1枚血怒：本次攻击威力+1。

### 风格牌
| 风格 | 距/力/速/韧 | 效果 |
|---|---|---|
| 恶魔 Demon Form | +0/+2/-1/+2 | 结束：若本回合你受过伤害，获得1枚血怒（每回合限1次）【v2.1受伤联动】 |
| 壁垒 Barricade | +0/+1/-1/+1 | 护甲2。前置：后退1~3（举盾后撤）。结束：若护甲未被全部消耗，剩余量（至多2）结转，下回合开始时获得之 |
| 献祭 Offering | +0/0/+1/0 | 展示：燃血1。若如此做，本回合速度+2 |
| 重刃 Heavy Blade | +0/+3/-3/0 | 前置：前进1~2（大剑压进）。本攻击每消耗1枚血怒：威力+1 |
| 勾拳 Uppercut | +0~1/+1/-1/0 | 命中：对手下回合威力-2、速度-1（震荡波式虚弱） |

### 专属招式
**恶魔之焰 Fiend Fire** ｜ 1~2 / 3 / 3 / 韧2
- 展示：你可以消耗任意张手牌中的风格牌（至多2张）：本次攻击威力+2/张。被消耗的风格跳过1次循环。

### 终结技
- **死神 Reaper** ｜ 1~2 / 4 / 4 / 韧2 —— 命中：你恢复等同于本攻击实际造成伤害的生命（不超过初始生命）
- **全身撞击 Body Slam** ｜ 1 / X / 5 / 韧3 —— 开始：威力+X。X为你当前护甲值的两倍（至少为2）【v2.1移除▲】

## 二、静默猎手（The Silent）

**干扰型 / 中级** · v3.1（回调压强度版：涂刃2毒/催化至多4/死亡绽放每2枚/淬毒决策阀）

### 特殊能力：致命毒素
- 对手可以拥有毒素标记，至多6枚。
- 结束：对手受到等同其毒素数的削命，然后移除1枚毒素。
- 你的风格与专属招式可使对手获得毒素；部分效果对中毒对手有加成。

### 风格牌
| 风格 | 距/力/速/韧 | 效果 |
|---|---|---|
| 涂刃 Envenom | +0/+1/+1/0 | 命中：对手获得2枚毒素；你前进1~2 |
| 淬毒 Noxious | 0/+1/0/0 | 结束：对手获得1枚毒素；3+毒素：改为2枚（毒势加速）。对手可以选择消耗全部毒素：受到等同数量一半（向上取整）的削命（决策阀）。后置：前进或后退1~2（杂技跳） |
| 催化 Catalyst | +0~1/0/-1/0 | 展示：对手毒素翻倍（至多4）。前置：你可以弃1张手牌中的风格牌：获得1点能量（弃牌求爆） |
| 残影 Afterimage | 0/0/+2/+2 | 结束：后退1~2（残影遁走） |
| 弱化 Crippling | 0/0/+1/0 | 命中：对手下回合攻击对你造成的伤害-2（结算层虚弱）。命中，3+毒素：对手再速度-1（毒发联动） |

### 专属招式
**死亡绽放 Die Die Die** ｜ 1~2 / 3 / 4 / 韧2
- 展示：你消耗对手的全部毒素：每2枚毒素，本次攻击威力+1（至少+1）。

### 终结技
- **毒爆 Corpse Explosion** ｜ 1~2 / X / 4 / 韧2 —— 开始：威力+X。X为对手毒素数×2。命中：移除对手的全部毒素
- **幽魂 Wraith Form** ｜ 1~3 / 4 / 7▲ / 韧0 —— 本回合你无法被命中或受到伤害；结束：你下回合速度-2（无实体的代价）

## 三、故障机器人（The Defect）

**法师型 / 高级** · v1.3（电涌推拉＋霜冻甲2＋时点统一"开始"）· 外号：鸡煲

### 特殊能力：充能球槽
- 你有3个球槽与球供给区（每种球各2枚）。Setup：1号槽放闪电球，3号槽放霜冻球。
- 开始：按槽位从左到右结算每个球：闪电球=对手削命1；霜冻球=你获得护甲2（当回合有效）；黑暗球=黑暗计数物+1。【v1.2时点修正；v1.3霜冻甲1→2】
- Ante：你可激发1个球（移出游戏）：闪电球=对手削命2；霜冻球=你获得护甲3；黑暗球=对手受到等同黑暗计数物的削命，然后计数物归零。
- 展示（经由卡牌效果获得球时）：将新球放入空槽；没有空槽则挤出最左槽的球——被挤出的球立即被激发。
- 集中计数物（至多3）：所有球的效果数值+集中数。

### 风格牌
| 风格 | 距/力/速/韧 | 效果 |
|---|---|---|
| 充能 Channel | 0/0/0/+1 | 展示：你从供给区获得1枚闪电球 |
| 冰川 Glacier | 0/+1/-1/0 | 展示：你从供给区获得1枚霜冻球。前置：后退1~2（冰川滑退） |
| 增幅 Defragment | 0/0/-2/0 | 展示：你获得1枚集中计数物 |
| 电涌 Ball Lightning | +0~2/+2/+1/0 | 命中：推动或拉动1；激发1个闪电球 |
| 递归 Streamline | 0/+1/+1/0 | 结束：若你本回合未命中，你弃牌堆中最早的风格立即回手 |

### 专属招式
**爪击 Claw** ｜ 1~2 / 2+X / 4 / 韧1
- 开始：威力+X。X为本局你使用爪击的次数（每次使用后放置1枚爪击计数物）。

### 终结技
- **雷雨 Thunder Strike** ｜ 1~3 / X / 5 / 韧2 —— 开始：威力+X。X为本局你被激发过的闪电球数×2
- **流星撞击 Meteor Strike** ｜ 2~4 / 9 / 3 / 韧3 —— 结束：你获得2点能量（等离子球）；展示：对手获得1枚等离子标记——其下个投注阶段不能使用

## 四、观者（The Watcher）

**殴斗型 / 高级** · v2+（暴怒前压修正）

### 特殊能力：无极姿态
- 你持有一张姿态卡（平静面/愤怒面），始终处于其中之一，开局为平静。
- Setup：你拥有3枚奇迹计数物。
- 平静：无效果。离开平静时（切换到愤怒或神格）：获得1点能量；结束，若你处于平静：回收1枚奇迹计数物（至多3枚）。
- 愤怒：你的攻击造成的伤害翻倍；你受到的伤害翻倍。
- 投注：你可以消耗3枚奇迹计数物：进入神格——本回合你的攻击造成三倍伤害；结束：进入平静（尖塔Mantra攒3进神格原味；平静每回合攒1，3~4回合一波）。【v3，2026-11-19机制重做，取代"第三次切换"姿态轨】

### 风格牌
| 风格 | 距/力/速/韧 | 效果 |
|---|---|---|
| 暴怒 Eruption | 0/+3/-1/0 | 展示：进入愤怒。前置：前进1~3（爆发前冲，强制前压为代价） |
| 凝神 Vigilance | 0/0/+1/+2 | 展示：进入平静。开始：后退1~2（警惕后撤）。静止式护甲1（进入平静的当回合） |
| 怒击 Tantrum | 0/+1/+1/0 | 若你处于愤怒：威力+1。命中：前进1~2 |
| 洞见 Third Eye | 0/0/+2/0 | 展示，若你处于平静：获得1点能量 |
| 坚忍 Fortress | 0/+1/0/+1 | 静止式护甲1 |

### 专属招式
**终式 Conclude** ｜ 1~2 / 5 / 3 / 韧3
- 结束：进入平静（大打之后急流勇退）。

### 终结技
- **神格 Divinity** ｜ 1~2 / 4 / 6 / 韧0 —— 展示：本回合你的攻击造成三倍伤害；结束：进入平静（空挥保护：本回合未命中则+1能量）【v3.1去▲】
- **天陨 Ragnarok** ｜ 1~3 / 7 / 4 / 韧2 —— 无特殊效果

## 附录二：状态卡（跨回合持续效果提醒物）清单

> 官方规则（v4.2 p14）：绝大多数加成仅当回合有效；少数持续到未来的回合加成，**以状态效果卡放入场上作为提醒物**。
> 制作规范：卡面写明效果与持续时长；标记类（Token/计数物）走供给区/消耗区系统，不需要状态卡。

| — | — | 愤怒的持续由姿态卡本身承担（官方"形态卡"用法：v4.2 p15 特殊卡双面规则，同时只能处于一种形态）；其余效果均当回合结算，无需提醒物 |

### 通用制作备注
1. 所有"下回合生效的 debuff/buff"共用同一模板：**一面写效果，一面写归属角色**，避免和对手的状态卡混淆；
2. 观者的姿态卡属于官方"形态（Form）"类特殊卡，参考凯莉斯塔/扎米塞尔的官方做法——本身是牌，不是提醒物；
3. 鸡煲的【球槽】同理：它是机制本体而非提醒物，优先级最高；
4. 毒素、血怒、集中等全部走 Token/Counter 体系（圆形标记+五边形计数物），不印卡。
