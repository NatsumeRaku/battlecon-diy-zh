1. 选六分类原型 → 2. 一句话核心机制 → 3. 五风格(1纯数值+2机制联动+1极端+1工具/位移,**至少1推拉**) → 4. 专属+双终结 → 5. E级安检(两字风格名/查重) → 6. EP核算(1威=1EP锚) → 7. 时点合规 → 8. 三角检核 → 9. 入评分表 → 10. 进竞技场实测

## 三轮自检（用户钦定 2026-11-20，每次 DIY 后强制执行）

设计完成后、交付前，必须逐条过以下三轮检查，每轮输出"检查项 → 结果 → 修正"清单。**全部通过才能定稿；任一轮不通过，回设计环节修正后重新过三轮。**

### 第一轮 · 规则冲突检查
- [ ] **v4.2 规则冲突**：护甲是否误写成跨回合？（回末过期，结转须明文）削命是否误写成可致死？（雷森零时式明文例外除外）韧性判定是否为"超过"？自动眩晕是否被写成可被韧性/护甲挡？无限韧性 vs 眩晕免疫是否混用？
- [ ] **自洽性**:X 值的定义时点是否写明？计数物溢出如何处理？消耗/跳过循环后会不会无牌可出（软锁）？转化类效果（伤害转毒/易伤加成/伤害翻倍）的结算顺序是否写明且无歧义？
- [ ] **与既有阵容撞车**：E 级查重（风格名两字+全库）；机制是否与官方 76 人+DIY 现役同质化（列出最相近的 3 个及区分点）。
- [ ] **边界情况**：多人局是否适用？不适用是否明文限定 1v1？对手无标记/计数物为 0 时效果如何？

### 第二轮 · 时点严谨检查
- [ ] **时点词合法**：每个效果必须标注时点八词之一（展示/开始/前置/命中/伤害/后置/结束/循环），禁止自创时点。
- [ ] **时点有效性**：影响先手的增益只在投注/展示；护甲直书"护甲 X"于效果栏；X 威力在开始时点结算；跨回合 debuff 注明生效回合+所需状态卡。
- [ ] **结算轴走查**：沿 展示→开始→前置→判距→命中→伤害→后置→结束→循环 逐步推演本角色每张牌，确认无悖论、无嵌套死循环、同时机触发顺序明确。
- [ ] **先后手语义**：同卡多效果的执行顺序、与对手效果的互动（谁先结算）是否写明。

### 第三轮 · 叙述合规官方检查
- [ ] **术语逐词核对** battlecon-glossary：时点八词、位移五件套（前进/逼近/后退/推动·拉动/瞬移）、越过、护甲写法、削命、能量、命中、开始、▲、* 固定数值。
- [ ] **官方句式**：`时点, 条件(X+资源/状态/距离), 可选: 效果`；条件不满足整个触发跳过。
- [ ] **数值记法**：四栏（第四栏数字=韧性/盾=眩晕免疫）；护甲不入四栏；位移三式（单值/区间/含 0=至多 X）；逼近只接单值。
- [ ] **命名**:风格名全两字+全库查重；专属/终结技名无撞名；外号不入卡名（初·/本名命名约定）。
- [ ] **组件清单**：列出所需全部计数物/标记物/状态卡。
