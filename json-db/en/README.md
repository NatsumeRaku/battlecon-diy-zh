# json-db/en 英文库说明（v0 骨架·2026-11-22）

## 建库原则（用户拍板 B 案）
1. **只录官方英文原文，禁止回译**——zh 是英译中的成果，回译会造成译文漂移，污染数据链。
2. 结构与 `json-db/zh` 完全同构：同目录、同文件名、同字段，便于双语对照与引擎复用。
3. 数值（距离/威力/速度/韧性）为语言中立的卡面数据，随骨架携带。
4. 无官方英文源的文本字段留空 `""`，文件级 `英文状态` 标记待补范围。

## 范围
- 已建：毁灭篇-DEV（35 角色）、战争篇-WAR（5 角色）、线上版-BCO（24 角色），共 557 文件。
- 暂不建：DIY 系列（崩坠/杀戮尖塔/街霸6/鸣潮），待 zh 稳定后再议。
