# 战链符号⇄字符串 映射对照表 v1.0(2026-11-22)

> 规则一(双轨制):存储层写字符串标签,展示层自动反向渲染为符号/中文尖括号。规则二(空心化):同一符号的空心/线框版=白·正面·未激活;实心版=灰·背面·已激活——双面元素正反区分优先用同符号空心/实心变体,不得另造新符号。

## A. 角标/数值标记(15项)
| 存储标签 | 展示符号 | 含义 |
|---|---|---|
| <red-diamond> | ◆ | 风格①红·斜方形 |
| <orange-pentagon> | ⬟ | 风格②橙·五边形 |
| <yellow-hexagon> | ⬡ | 风格③黄·六边形 |
| <green-triangle> | ▼ | 风格④绿·倒三角(勿与▲破局混淆) |
| <blue-circle> | ● | 风格⑤蓝·圆形 |
| <gray-moon> | ☾ | 独有招式(灰月亮) |
| <purple-star> | ★ | 变招切换卡(紫五角星,编外第六色) |
| <star8-alpha> | ✳ | 终结技α面=空心八芒星=白=正面(未激活侧展示用) |
| <star8-beta> | ✴ | 终结技β面=实心八芒星=灰=背面(已激活侧) |
| <shield> | 🛡 | 眩晕免疫(韧性栏图标,非角标) |
| <group-attack> | ◆ | 群体攻击效果标记(与风格红◆官方同符号双用,效果维度) |
| <initiative> | ▲ | 破局/决胜(嵌速度值内) |
| <fixed> | * | 固定值(不受修正) |
| <corner-num> | 角标N | 弃牌堆建议编号(卡面右下,非强制) |
| <watermark> | • | 第4版水印符(水印文字前) |

## B. 格式标签(9项)
| 存储标签 | 展示渲染 | 适用 |
|---|---|---|
| <g-bold>…⟨/⟩ | 绿粗体 | 开始/结束时点短语(时点词+条件整段) |
| <r-bold>…⟨/⟩ | 红粗体 | 命中/伤害时点短语(含条件整段) |
| <k-bold>…⟨/⟩ | 黑粗体 | 展示/循环短语+"初始设置"四字+护甲X/削命X |
| <b-bold>…⟨/⟩ | 蓝粗体 | 前置/后置时点短语 |
| <b-i>… | 粗斜体 | +X速度/+X威力/+X韧性、X计数物(1假面/2专注) |
| <i>… | 斜体 | 括号补充说明、标记引用(1血怒/1酒意) |
| <p-instant>…⟨/⟩ | 紫粗+灰底 | 即时触发(每当/当…时),灰底盖该句不波及其他时点 |
| <o-ante>…⟨/⟩ | 橙粗+米色底框 | 【对手】投注条款 |
| <song>…⟨/⟩ | 宋体(小字=风味引文) | 人物技能概述段/机制名上卡/风味引文 |

## C. 规则二应用示例
- 终结技双面卡:展示α面内容时角标渲染✳(空心·白·正面);β面✴(实心·灰·背面)。实卡如此印刷(灵魂陷阱=白✳/灵魂之门=灰✴等全角色一致)。
- 未来凡双面卡/双色元素(形态牌激活面等)的正反区分,一律用同符号空心/实心变体,空心侧永远=白/正/未激活。
