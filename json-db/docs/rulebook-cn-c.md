# 战链 v4.2 官方中文规则书·整本载录(第C册:书页31-39)

> 规则裁定优先级链:①中文规则书(本档) ②模式指南 ③英文规则书 ④用户口述;例外:用户以"规则书是这么说的"裁决时视同规则书原文(最高)。

## 第31页·其它效果和关键词(下)
- **无视韧性**:被这种攻击命中时,无论实际韧性数值是多少,都直接视为"0"。
- **N/A距离或威力**:距离N/A的攻击不会命中对手;威力N/A的攻击在命中时不造成伤害(无论其他效果给威力提供了怎样的强化)。这些卡牌上的特殊效果通常会改变你的距离,用另一项数值覆盖N/A。游戏效果需要检查你的距离或威力数值时,"N/A"被视为"0",总距离或总威力也变为"0"。
- **拿起风格/招式**:拿起风格和招式(无论它们在哪里)到你的手中。
- **执行一个触发**:如同被正常激活一样,执行这个触发的所有步骤。
- **回复生命**:让触发这项效果的斗士回复指定数值的生命;总生命不能超过你的起始生命。
- **支付生命/计数物**:你可以支付指定的资源来获得特定的效果;你不能支付最后一点生命,也不能支付不在你供应堆中的生命或计数物。
- **数值变为X**:将你的数值改变为指定数值,无视距离、威力、速度或韧性的印刷数值和所有生效的强化、惩罚。
- **眩晕免疫(🛡)**:你不能被任何效果或伤害眩晕。当一张卡牌拥有眩晕免疫时,一个护盾图标会取代这张卡牌的韧性数值作为提示。如果有任何效果需要这名斗士的具体韧性数值,这个护盾图标被视为"0"。
- **破局(▲)**:如果任意斗士拥有破局来修正他的速度,就不会发生激斗。如果双方的速度相等,拥有破局的斗士或团队会赢得平手。如果双方(斗士/团队)都拥有破局,那么上个回合中的先手玩家仍作为先手玩家。
- **脆弱**:对手无视你的护甲和韧性——伤害不能被减少,任何伤害都会导致你眩晕(除非你拥有眩晕免疫)。
- **你/对手被眩晕**:指定的斗士变为眩晕;无视这名斗士拥有的护甲和韧性,但不能绕过眩晕免疫;一名斗士只能被眩晕一次,对已被眩晕的斗士不会有进一步的效果。
- **你每次最多受到X伤害**:在斗士受到伤害并用护甲减少伤害之后生效;防止伤害中超过X的部分;被防止的部分不计入使斗士眩晕的伤害。
- **你的生命不会减少到1以下**:任何会将生命降到1以下的伤害部分被防止;被防止部分不计入眩晕伤害。
- **未占据格**:不包含立像的格(标记物不会占据一格)。
- **取回**:拿取指定的被移除的配件,并将其加入到玩家的供应区中。
- **印刷**:"印刷"数值指无视所有修正(但包括印刷在风格数值框中的修正数值)的情况下,攻击的一项指定数值。

## 第32页·多人模式(章节扉页)
多人模式推荐给已熟悉游戏的进阶玩家;可让3或4名玩家一同游戏;进阶玩家也可使用这项规则控制两名斗士进行更具策略性的单人玩家对决。可能需要多套《战链》或通用指示物表示额外玩家的能量与生命。

## 第33页·多人模式的规则概述
- **团队移动**:移动时跳过友方和敌方;两个立像不能位于同一格;前进可朝任一方向(只要朝着一名对手移动);后退可朝任一方向(只要远离一名对手移动)。
- **团队共享能量**:每名团队成员在循环阶段中单独拿取能量,整个团队共享一个能量池;每名斗士可单独使用每种超载板块。
- **确定速度**:团队成员之间速度相等时自行决定顺序;多人模式中不会发生激斗;若原本会发生激斗且没有玩家拥有破局,拥有先手玩家牌的团队获得破局。
- **攻击的目标**:命中的在你的攻击距离内任一方向最近的对手。
- **触发的目标**:"对手"指离你最近的那一名对手;执行命中和伤害触发时,"对手"指你刚刚命中的那一名对手;当任一斗士可以将你视为"对手"(你是离他最近的对手)时,这名斗士可以使用你的【对手】投注效果。
- **在多人模式中被击败**:你的幸存队友共享一张复仇参考牌。在游戏中可能会因此获得多张复仇参考牌。被击败的斗士的所有配件立即移出游戏。

## 第34页·团队初始设置/团队移动/团队投注
- **团队初始设置**:团队游戏中玩家照常选择斗士;劣势团队(2对1或3对1)可使用一名超级或终极斗士平衡游戏(第37页详介);团队游戏使用9格战场版图(2人战场版图背面);团队一名斗士必须在团队起始格开始,其他成员在其身前/后任意格,玩家自由决定前后位置;随机决定哪个团队获得先手玩家牌,先放置斗士。游戏开始时每多一名角色,能量计数物堆额外+20能量(**2对1=65能量;2对2或3对1=85能量**)。
- **团队移动**:移动时跳过所有友方斗士和敌方斗士,一次移动效果可能跳过多个格。(凛示例)
- **团队投注**:投注以团队形式交替进行;你的团队投注时可选择任意一名斗士投注;另一团队接着投注;双方团队连续跳过则投注阶段结束;队友共用一个能量池;每名成员可单独使用每种超载板块。

## 第35页·团队展示+速度/攻击的目标
- **团队展示+速度**:多人模式不会发生激斗。展示步骤中,展示的单个最高速度的斗士所属的团队获得先手玩家牌,其余玩家按速度递减排列。速度相等且双方都没有破局时,拥有先手玩家牌的团队赢得平手;同一团队斗士速度相等可自行决定顺序。从先手玩家开始按速度顺序,每名玩家依次像标准游戏一样单独执行攻击。
- **攻击的目标**:攻击会命中攻击距离内**任一方向最近**的那一名对手;照常造成伤害并激活效果。只要有可能,就必须选择并命中攻击距离内的一名对手。多人模式中一名玩家可能被命中多次;韧性作用于一个回合中受到的总伤害。**提醒:"当…时"触发只会执行一次。"每当"触发可以执行多次。**
- (示例角色:希尔纳奥/凯/达吉因/温蒂/科拉/维基尔/安雅)

## 第36页·"对手"是谁?
- 游戏中的卡牌使用"对手"来指代能够作为其效果目标的玩家。多人模式中"对手"指满足特定条件的敌方斗士:**"对手"是你的立像两侧距离你最近的敌方斗士**;所有敌方斗士同侧则答案简单;两侧都有时可在两侧最近的敌方斗士中选择一个。存在符合规则的目标就必须选择一个。
- callout:"命中"和"伤害"触发效果确定"对手"的方式不同——对这些效果而言,"对手"总是你刚刚命中的那名斗士,无论距离如何;由"被命中"或"回避特定命中"触发的效果,"对手"指正在尝试命中你的玩家。
- 为对手提供投注行动的斗士:这些投注对任何将你视为"对手"的斗士(一个方向上距离你最近的任意敌方斗士)都可用;**敌方团队每个回合只能使用一次这种投注**(无论哪个敌方斗士使用)。

## 第37页·团队的能量/在多人模式中被击败/2对1超级斗士/3对1终极斗士
- **团队的能量**:每名成员单独拿取能量(**通常拿取1能量,如果生命小于或等于7则拿取2**),加入团队总能量;被击败的团队成员每个回合额外生成2能量(详见复仇参考牌)。**一个团队的总能量不能超过20。**
- **在多人模式中被击败**:斗士被消灭时,其所有配件(立像/标记物/状态效果/指示物等)与所有卡牌移出游戏;将复仇参考牌加入游戏提示幸存队友;**3对1游戏中幸存队友可能获得2张复仇参考牌(叠加它们的所有强化)**。
- **2对1:超级斗士**:超级斗士是更为强大的斗士,足以同时对抗两名对手;超级斗士参考牌介绍如何设置斗士及战斗强化。
- **3对1:终极斗士**:终极斗士是举世无双的斗士,足以同时对抗三名对手;终极斗士参考牌同上。
- (卡图:超级参考牌威力+2/速度+1▲/韧性+3;终极参考牌威力+3/速度+2▲/韧性+4/护甲2/每回合每种超载3次/循环21+→4·11-20→5·≤10→6)
