# 战链《模式指南》整本载录(官方中文·23页)

## p1(书页4-5)·变体与竞技场
- **超凡与无限招式替换规则**:用超凡/无限招式**替换标准招式**(不拿超级/终极参考牌加成,保留单人斗士增加过的总生命);超凡建议1对2、无限建议1对3——官方第二种首领玩法。
- **乙型招式**:可替换标准招式/乙型vs标准对决/混合搭配打造斗士。
- **竞技场(Arenas)**:12张双面场地卡;开局设置,初始设置最先执行;同时点触发先于斗士;**"全员"修正**=触发视为属双方斗士;能量计数物来自游戏盒;1v1设计不建议叠多人模式。

## p2-5(书页6-9)·首领剧本(Boss模式)
核心规则全套(见battlecon-modes.md首领剧本节,已入库):架势(速度+韧)/套路(距离+力)/生命25×敌方数/击破/首领护甲共享/不可击破/闪避特殊规则/数值比较视为0/首领不能超载用特技投注。四首领套件:巨龙伯尔曼(1+8+13)/犹斯塔(1+8+14)/浩劫(1+10+10)/暮色之玛格德莉娜(1+1+4英灵架势+14套路)。

## p6(书页10)·战斗探索地城(BattleQUEST)总规则
单人与多人;穿房间打怪,房间表现决定路线;过关后生命保持,其他重置;团队地城=各控1斗士(被击败者下层以1生命回归);结伴地城=1控2(循环可换人,共享能量);**能量无堆直接从盒取**;全灭失败可重试该层;怪物:每回合6个指示物洗混面朝下发1个/只,展示时数字决定攻击;移动保持目标在攻击距离内尽可能远;玩家代做决定(挑战模式从怪物角度最优);怪物不投注(被给投注则最大化用,如雷克森诅咒/亚历克希安骑士精神立即用);不弃牌(被迫弃牌则明置弃1指示物,下回合结束前不回堆);玩家总是胜过怪物。
