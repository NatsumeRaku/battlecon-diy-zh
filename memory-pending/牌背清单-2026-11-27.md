# 牌背清单（状态效果牌 / 特殊牌背面）· 2026-11-27

## 一、判据

用户指认：立绘美术上覆**灰色斜条纹**的格子，是角色**状态效果牌／特殊牌（饮品之类）的牌背**，不是立绘。

可操作判据：**同一图版内连续多格图像完全相同**（32×32 缩略均差 < 4）。正常卡面每格不同；牌背是同一张图重复贴在多格上（一个角色的全部状态牌共用一个背）。

复核方式：51 组代表格全部目视确认。B 系列 + F_11_c19 组 + F_23_c35 组共 206 格成立；F 系列其余 21 组经目视为正常卡面（有卡名／效果／数值栏）或切片不全灰块，不计入。
