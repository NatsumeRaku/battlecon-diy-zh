# 战链DIY卡面印刷规范

## 一、色彩层（保真规则）
- 风格条：红/橙/黄/绿/蓝/紫 = 对应角标颜色
- 数字条：距离蓝/威力红/速度黄/韧性绿
- 底色：白色=正面未激活，灰色=背面已激活
- 角标：空心=未激活，实心=已激活

## 二、版式
- 效果区：宋体，12pt，黑色
- 标题：黑体，14pt
- 数值：Arial Bold，18pt
- 角标位置：卡名右侧/右上角

## 三、终结技双面卡
- α面（正面）：白色底，空心符号，卡名无"变招"
- β面（背面）：灰色底，实心符号，卡名"变招"标记
