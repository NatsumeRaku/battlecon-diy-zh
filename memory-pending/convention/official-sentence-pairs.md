# 官方句对锚点库(v1·2026-11-22)

> 9角色全套实卡挖出的"英文模式→官方中文"句对,延伸翻译与DIY卡面的查询表。右列括注出处角色;X/Y处按需填值。

## 一、时点句式
| 英文模式 | 官方中文(出处) |
|---|---|
| Start: ... | 开始:…(全员) |
| Start, optional: ... | 开始,可选:…(玛玫莉障壁) |
| Reveal, if you didn't ante a Seal: ... | 展示,未投注封印:若你展示了一张"变招"之外的风格,你的风格会被取消(数值修正被视为+0,并且效果不会触发)。(米哈伊尔UA) |
| Recycle, range 1, you weren't stunned: ... | 循环,距离1,你未被眩晕:回收1晶化。(阿德婕娜UA) |
| Recycle, if neither you nor your opponent was hit: ... | 循环,你没被命中并且你没有命中任何对手:回收所有被投注的诅咒。(雷克森UA) |
| End, if you took damage: ... | 结束,受到伤害:回收1封印。(米哈伊尔UA) |
| Before, optional: ... / After: ... | 前置,可选:… / 后置:…(玛玫莉巫术/宏伟) |
| Hit, optional: ... | 命中,可选:…(玛玫莉五风格) |
| Damage: ... | 伤害:…(谢珂图尔掠夺) |
| Whenever [trigger]: ... (in-time) | 每当[触发]:…(灰底紫粗即时条款,拜伦无心/雷克森/米哈伊尔/茹妮卡UA) |
| When you are hit: ... | 当你被命中时,…(雷克森/米哈伊尔/茹妮卡UA) |

## 二、支付成本
| 英文模式 | 官方中文(出处) |
|---|---|
| Pay X Focus to... (1~5, each...) | 支付1~5专注,每支付1专注就获得护甲1。(玛玫莉抵消) |
| Pay X to eliminate your opponent | 支付6晶化来消灭对手。(阿德婕娜UA——"支付X来Y"成本句式) |
| Remove Force equal to your life | 移除等于你生命的能量(变招全员卡) |
| Spend X [token] | 消耗1假面(拜伦)/消耗1封印(米哈伊尔)/使用1封印指示物(米哈伊尔UA——"使用X指示物"句式) |
| [Opponent] Ante: pay 1 of X's [token], gain +1 Power and +1 Speed | 【对手】投注:支付亚历克希安的1骑士精神,获得+1威力与+1速度。(亚历克希安UA) |

## 三、条件与选择
| 英文模式 | 官方中文(出处) |
|---|---|
| If you advanced 2+ spaces and didn't move past the opponent: +2 Power | 若你因此移动了2或更多格并且没有移动越过对手,+2威力。(亚历克希安坚定) |
| If you cannot, you are destroyed | 若你无法做到,你被消灭。(拜伦无魂) |
| If you cannot (because you already have all of them), lose 2 life | 若你无法做到(由于已经拥有所有诅咒),削命2。(雷克森UA——括号补充斜体) |
| The opponent must choose and discard 1 base | 对手必须选择并弃置1张招式。(加尔驾雨) |
| If you have fewer than 3, spend as many as possible | 若你的专注少于3,则消耗尽可能多的专注。(玛玫莉UA) |
| You have X counters. Spend the rest. | 你拥有2专注。消耗其余所有专注。(玛玫莉UA——"消耗其余所有"句式) |

## 四、替代与防止效果
| 英文模式 | 官方中文(出处) |
|---|---|
| Whenever you would take more than X damage, change it to X | 每当你将要受到多于1伤害时,改为受到1伤害。(拜伦无心) |
| When you would take more than 3 damage, if you hit this beat, change it to 3 | 每当你将要受到多于3伤害时,若你在本回合中命中过对手,就改为受到3伤害。(雷克森咒言) |
| The first time each turn you're hit for attack damage, that damage becomes... | 每回合首次你受到攻击伤害时,该伤害改为奥斯提HP-1(DIY对齐华彩骑士"钢铁之躯:伤害改耗耐力"先例) |
| When you're stunned, lose 3 Focus | 当你被眩晕时,消耗3专注(若你的专注少于3,则消耗尽可能多的专注)。(玛玫莉UA) |
| Stun immunity, Armor 2 | 眩晕免疫,护甲2。(茹妮卡犹斯塔光束) |
| Your artifacts cannot be deactivated | 你的神器不能被停用。(茹妮卡炼器之强欲) |

## 五、移动
| 英文模式 | 官方中文(出处) |
|---|---|
| Advance up to 6 | 逼近6(雷克森肃清——"逼近"=朝对手方向尽可能移动) |
| Move directly to any space behind your opponent | 瞬移至对手身后的任意格。(拜伦无息) |
| Push or pull 1-2 | 推动或拉动1-2(全员) |
| [Minion] moves 1 space (cannot pass over) | 奥斯提朝对手转移1格(不可越过)——随从标记的位置变更用"转移",不用"移动"(雷克森UA/亡灵契约师) |
| Retreat as far as possible | 尽可能后退(通用) |

## 六、计数物与档位
| 英文模式 | 官方中文(出处) |
|---|---|
| For each Curse you have: +1 Speed | 每拥有1诅咒就+1速度。(雷克森帝王的——"每拥有1X"句式) |
| If you have 3+ Focus: ... | 拥有3+晶化:+3威力(阿德婕娜诱惑——"N+档位"记法) |
| If the opponent has 3+ Curses: dodge | 拥有3诅咒:回避攻击(雷克森不屈——整数值条件式) |
| Ante: use 1 Malice to +1 Speed | 投注:使用1恶意来+1速度(谢珂图尔UA) |
| This attack cannot hit the opponent | 本攻击无法命中对手。(闪避) |
| Attacks at range 3+ cannot hit you | 回避在距离3+的攻击。(米哈伊尔圣洁) |
