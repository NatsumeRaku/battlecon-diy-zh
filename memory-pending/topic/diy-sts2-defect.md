# 故障机器人(StS2)v2.0(对齐先古v2.0范式·审计驱动)

> 记忆库写入故障,本文件为临时交付版;恢复后转入 topic/diy-sts2-defect.md。

## 特殊能力·燃料核心
- 你有*3球槽*(位置无关,至多同时持有3球)与球供给区:闪电×2、冰霜×2、黑暗×2、玻璃×2(每型2枚=终身供给,消耗区不可回收;玻璃球碎裂移除游戏同此)。
- 初始设置:将所有球放在供给区。生成1闪电球,1冰霜球。
- 开始:结算每个球槽中球的效果(顺序无关):闪电球=对手**削命1**;冰霜球=**护甲1**;黑暗球=黑暗计数物+1;玻璃球=上述效果翻倍。
- **生成**:将供给区1球放入空槽。若无法做到,先激发1球。
- **激发**:结算对应效果两次,消耗该球。**触发**=仅结算对应效果,不消耗(线圈)。
- 投注,你可激发1个球(由你选择哪个球)。【电池六十二:连兑温和增强,暂不加闸】
- 投注,消耗*1燃料*:获得*1能量*,或弃牌堆中最早的风格提前1回合回手。
- 集中(至多3,开局0):所有球效果数值+集中数。
- 黑暗计数物(至多5,开局0):由黑暗球累积;投注激发黑暗球=按当前数量削命后归零。
- **玻璃球特性**:每个结束阶段或它被激发时碎裂(移除游戏,不可回收)——供给仅2枚。

## 风格
回收·结束:你可以消耗1张手牌中的风格牌(跳过1次循环),获得*1能量* / 散射·展示:你可以消耗至多2张手牌中的风格牌,本次攻击每张+3威力;命中:推动或拉动1 / 线圈·命中:触发每个闪电球各1次 / 超频·展示:回收*1集中*;结束,若本回合没有消耗过风格牌:受到削命2 / 透镜·展示:生成1玻璃球

## 专属
爪击·开始:威力+X,X=本局爪击的使用次数。

## 终结
四重释放·开始:依次激发每个球各1次(由你选择结算顺序;玻璃球激发=效果翻倍并碎裂) / 碎裂·展示:碎裂所有在场玻璃球,每枚+2威力(至多+4)
