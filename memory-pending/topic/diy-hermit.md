# DIY角色 15:崩坠·隐士(The Hermit,Downfall)v1·不死枪手

> 记忆库新建故障,本文件为临时交付版;存储恢复后由工坊转入项目记忆库 topic/diy-hermit.md。

## 基础信息
- 出处:《杀戮尖塔:崩坠》第5英雄——不死枪手,被诅咒的流浪者
- v4.2分类:强攻型/中级——单核心机制(弹巢),明牌博弈
- 机制名:弹巢(Dead On 的位置感由弹头格继承;核心机制经用户裁定重构——手牌正中在实体桌上不可核实,牌背同纹)
- 系列命名:崩坠

## 特殊能力(UA卡,机制名:弹巢)
- 你有弹巢轮盘(6格,1-6号格,公开放置)与至多2枚实体弹。弹头标记开局位于1号格(公开)。
- 结束:弹头前进1格(6→1循环)——轮盘自转,不可控。
- 你的攻击结算时:若弹头所在格有弹:+3威力,移除该弹(射出);空弹格:无修正。
- 装弹:卡面效果可放置1弹至你选择的空格(至多2枚在巢;巢满则不能装)。

## 风格牌(5张)
| 风格 | 距/力/速/韧 | 效果 |
|---|---|---|
| 快枪 | 0/+1/+1/0 | 无额外效果 |
| 狙杀 | +0~1/+3/-3/0 | 无额外效果 |
| 滑步 | 距离+0~2/0/+1/0 | 前置:前进1~2 |
| 诅咒 | 0/0/-1/0 | 结束:受到削命1,装弹1(向黑暗面买弹药) |
| 爆头 | +0/+2/-2/0 | 若弹头格有弹:+2威力 |

## 专属招式
**死眼** | 距离1~3 威力4 速度4 韧性2
- 展示:旋转弹巢:将弹头移至你选择的格(稳枪瞄准)。

## 终结技(2张)
- **连发** | 距离1~3 威力5 速度5 韧性1 | 展示:每有1弹:+2威力;射出全部弹。
- **绝响** | 距离1~2 威力X 速度6▲ 韧性0 | 开始:威力+X。X=巢内弹数×3(至多6);射出全部弹,弹头归零至1号格。

## 角标
快枪=红◇/狙杀=橙⬠/滑步=黄⬡/诅咒=绿▽/爆头=蓝○;终结=✳α/✴β。(展示层空心;实卡印刷实心◆⬟⬡▼●)
