## 一、来源优先级与铁律（S8 / S10 / S9）

1. 官方中文实卡照片/盒面 ＞ 官方中文规则书 ＞ 官方中文模式指南 ＞ 英文规则书 ＞ 社区译文 ＞ 库存/记忆拟合。冲突以上级为准，下级标 `[待核]`。
2. 卡面文本逐字照录：数值/效果/时点以印刷值为准；角标/色彩层保真转录。
3. **引用禁令**：来源 ≠「官方实卡」的条目不得作为叙述参考/句式范例/规范依据。唯二合法叙述参考＝①来源「官方实卡」且用户未否决；②规则书/模式指南原文。
4. **官方五系列冻结**（WAR / DEV / BCO / 通用招式 / 首领）：已录效果文本「只进不出」，疑似错漏只标 `[待核]`，不得回改。自检清单适用于 AI 新译文本（无用户手录基线者），有手录基线者仅适用结构字段。
5. **en 树只录官方英文原文，禁止回译**（回译会污染数据链）；同目录/同文件名/同字段，与 zh 同构。
6. 双轨三层：存储层＝字符串标签（`<g-b>`、`<red-diamond>`、`<initiative>`）；展示层＝空心符号（⟨绿粗⟩◇▲）；印刷层＝实心（◆●▼）。日常输出用展示层，用户说「字符串版/给我原文」才直出标签。
7. 纯文本铁律：照片/密钥/对话原文不入库；裁定须提炼为准则文本后方可入库。

## 三、时点封闭集与句式（S4 / S3 §一）

**攻击对八词**：展示 Reveal ／ 开始 Start ／ 前置 Before ／ 命中 Hit ／ 伤害 Damage ／ 后置 After ／ 结束 End ／ 循环 Recycle。
**登记值**：初始设置 Setup ／ 投注 Ante ／ 当 Whenever/When（必带条件）／ 持续（常驻，印刷层省略前缀）。
**系列专属**：击破 Break（伯尔曼）／ 限定投注 Limited Ante（Lixis「病毒」）。

| 英文 | 时点字段 | 效果行文前缀 | 标签 | 背景键 |
|---|---|---|---|---|
| Start | 开始 | 开始： | `<g-b>` | — |
| Reveal | 展示 | 展示： | `<b>`（黑粗） | — |
| Before / After | 前置 / 后置 | 前置： / 后置： | `<bl-b>` | — |
| Hit | 命中 | 命中： | `<r-b>` | — |
| Damage | 伤害 | 伤害： | `<r-b>` | — |
| End | 结束 | 结束： | `<g-b>` | — |
| Recycle | 循环 | 循环： | 照实卡（多黑粗） | — |
| Ante / Limited Ante | 投注 / 限定投注 | 投注： / 限定投注： | `<o-b>` | 橙底 |
| Setup | 初始设置 | 初始设置： | 照实卡 | — |
| 常驻 | 持续 | 直书，零时点词 | 无 | — |
| Whenever / When | 当 | 当…时： / `<p-b>每当</p-b>`… | `<p-b>`（紫粗，只包「每当」二字） | 灰底 |

**「当」三条铁律**：①时点字段恒 `当`＋完整条件字段（含「当…时」）；②效果行文按「当…时：」照录原意，不反向改「每当」；实卡原印「每当，…：」变体逐字照录；③紫粗 `<p-b>` 只包「每当」，条件与冒号留标签外，禁「每当，」断句（插入从句按实卡照录除外）。

**同时点结算顺序**：由相关玩家自选，卡面文本禁自行钉死顺序。

**官方句式落实（S1 §六-B）**：
- Hit: X. If you did, Y. → 命中：X。若如此，Y。
- Reveal, [条件]: X → 展示，[条件]：X（条件与「展示」逗号相连，冒号后接效果）

- X per Y → 每 Y，X（修正值逆序归一入 `<i-sb>`）

## 六、翻译规范核心（S3）

### 6.1 修正值与数字排版
- 修正值短语整体入 `<i-sb>`，**逆序归一**：`威力+2`→`<i-sb>+2 威力</i-sb>`（±N 威力/速度/韧性/距离通用）；仅对四个钦定词逆序，自造词不得逆序。
- 计数物/标记名：数字连名整体入标签，量词（面/个/枚/张）省略不入标签（`<i-sb>3 护盾</i-sb>`）；实体牌保留量词「张」：`弃置 <i-sb>1</i-sb> 张招式`。
- 已入 `<b>` 的护甲/削命短语不回溯；数字与文字相连侧空一格、与标点相连侧省略；标签视为透明。
- 范围：数值属性用 `~`（`1~3`）；移动词引导的动作范围用 `-`（「推动或拉动 1-6」）；风格修正值强制带符号 `+N/-N/+0`；基底/专属/终结技绝对值直出；`N/A` 照常印刷。

### 6.2 标记增减动词（封闭）
- 标记减少：回收 / 支付 / 消耗 / 使用 / 移除（禁自造）。
- 非标记资源（护甲/能量/生命）：获得 / 生成 / 放置（禁与标记混用）。
- 计数必须实体化：「每有 1 X」「X+ 档位」禁台账式叙述。
- 代价句式：支付 X 来 Y / 消耗其余所有 / 若你的 X 少于 N，则消耗尽可能多的 X。

### 6.3 移动词（封闭）
| 英文 | 中文 | 备注 |

### 6.5 条件与选择句式
- If you cannot… → 若你无法做到（括号补充斜体）

### 6.6 段落级规则
- **楷体描述段**（UA 技能说明段）：一切规则文本规律不适用，逐字照录；仅允许 `<sb>` 标实卡半粗，`<i-sb>`/`<b>` 不入此段。
