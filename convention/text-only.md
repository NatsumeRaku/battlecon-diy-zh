# 纯文本铁律

## 一、仓库可见性

本仓库已转为 **公开（Public）**。

## 二、铁律

1. **照片/图片一律不上传**：本仓库为纯文本仓库，任何实卡照片、卡面扫描、图片素材严禁进入版本库。沙盒本地照片保留在本地，不上传、不推送。
2. **密钥严禁入库**：GitHub token、.git-credentials、任何凭据与密钥严禁推送到本仓库。
3. **激斗优先**：资料冲突时，用户贴出的原文永远优先于拟合或抓取的数据。
4. **对话内容不入库**：仓库中不出现直接对话内容；凡对话中沉淀的裁定，一律提炼为准则文本（如本文件）后方可入库。
5. **JSON 只存放实卡内容**：数据库 JSON 仅存放卡面本体数据（卡类/名称/角色/系列/角标/数值/效果/来源），核验资料与注释归档到对应的 md 层。
