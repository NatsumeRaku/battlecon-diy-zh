# 项目纯文本化铁律(用户2026-11-22裁定,最高优先级)

## 规则
1. **本项目只有纯文本内容。** 照片、截图、扫描件等一切图片文件:不推送GitHub、不存档output、不打包zip。
2. **照片的处理方式=读取→转录→即删**:用户上传实卡照片后,读取并将文字/角标/色彩层信息转录入记忆库(仍受 source-precedence 第5-8条"实卡最高优先级"约束——转录必须逐字、保格式、录角标),转录完成后删除照片文件。
3. 已执行:2026-11-22删除output下8个照片目录(camera0/1/2、cam1b、jiaer、burman-boss、rulebook-cn、modes-guide,共约215MB);GitHub仓库battlecon-diy-zh全程未提交任何照片。
4. 波及修正:仓库README与记忆库中凡提到"实卡照片存档"的表述,均按"转录文本为准、照片不留"理解。
5. 例外:无。即使照片是最高优先级信源,其载体也不留存——**优先级属于信息,不属于文件**。

## 操作自查
- 推送/打包/备份前:检查文件清单,含 .jpg/.jpeg/.png/.webp/.gif/.bmp 一律剔除。
- 用户再传照片:读完转录后主动删除,并告知用户已删。
