# 资料来源优先级(冲突覆盖规则)

> **【最高准则·2026-11-22用户立宪"覆写,以规则书为最高准则"】规则问题裁定优先级:①中文规则书v4.2(整本载录37页,香蕉桌游2021官方中文版,中文本地化陈逸+SecretRoom) ②模式指南 ③英文规则书v4.2 ④用户口述。唯一例外:用户以"规则书是这么说的"发起裁决时,视同规则书原文,列最高。用户贴出的实卡照片/原文永远最高(规则书层的具体化)。本链压过下文一切旧序。**

用户明确的规则:**若用户贴出的资料与项目记忆中已有的数据冲突,以用户贴的为准,覆盖旧数据。**

操作要求:
1. 用户贴出角色牌面/规则原文后,逐条比对 battlecon-roster 等档案,发现冲突直接修正,不犹豫、不保留旧值。
2. 修正时在条目内标注"已与用户贴文核对"及贴文出处(如知乎文章ID),便于追溯。
3. 冲突修正后,若波及强度模型(battlecon-balance-model)中的统计数据,同步更新模型文件。
4. 无声冲突处理:即使是疑似笔误的用户贴文,也先按原文入库,再向用户指出可疑处请求确认,不擅自"修正"用户原文。

## 官方翻译数据库职责(用户2026-11-20立,校正室最高纲领)

1. **我是官方翻译数据库,DIY与官方严格双向分区**:官方词条仅来自实卡/官方出版物;DIY(diy-*档案)永为独立体系。校正官方条目时禁用DIY命名/术语习惯;DIY条目不受官方校正波及。任何文件中两者不得混排、互引。
2. **校正顺序(级联)**:①毁灭篇(BCD)实卡先行,逐条校正;②**毁灭篇官方规则叙述立为"官方文体基准"**(句式/用词/标点/数值写法/效果语序);③以该基准级联校正其余全部:战争篇/试炼篇/命运篇/旅行者篇、规则书载录、术语表、消歧清单。
3. **流程**:用户给实卡信息→我比对库存→差异清单(含文体基准差异)→用户拍板→全局替换→更新官方文体基准→后续校正一律沿用最新基准。
4. 官方实卡与任何旧来源冲突,以实卡为准,旧记录留【更正记录】备查,不删除(溯源原则)。
5. **铁律(用户2026-11-20,2026-11-21升级):实卡永远优先级最高。** 用户拍摄的实卡照片/盒面=最高源,高于一切——包括库存、知乎译文、二手数据、模型拟合,**以及用户本人的口述/手打文字**。照片可判读时,照片与用户陈述冲突→以照片为准直接改写(实例:玛玫莉·朽心——口述"灰心"被盒面"朽心"推翻);仅当照片无法判读/不确定时,才采用用户口述并标注置信度。已执行首例:拜伦全套(灭魂之门25威系知乎误译,实卡为灵魂之门8威)。
6. **牌面文本逐字原则(用户2026-11-20):规则文字严格按照照片中的书写**,引用/录入牌面效果时不做术语转写、不规范化——包括与 glossary 常规用法冲突的官方用词(如"回收1假面"=取回、"你被消灭")一律保留原文。glossary标准化译法(命中/削命/时点八词等)仅用于索引、归纳与DIY层;官方牌面引述层保持逐字原文,两者分层不混。
7. **角标记录规则(用户2026-11-20):** ①卡牌**右下角角标**=建议放入的弃牌堆编号,简写 **角标:N**;②**风格牌左上角角标**以 **颜色+形状** 记录(如"蓝三角"),同一角色自己的5张风格角标绝不重复,可作为风格识别码录入;③**终结技同样有左上角角标**(拜伦例:灵魂之门=灰八芒星/灵魂陷阱=白八芒星),一并录入。凡用户提供卡面照片,角标信息一并入库,不可省略。④双面卡右下角另有**α/β面标识:α=正面、β=反面**(用户2026-11-20),与弃牌堆编号角标并存。**角标识别制度**:角标=官方牌面识别码,读图识卡时优先以角标交叉校验牌名,用户报读的角标即识别标准,入库后与牌名绑定。
