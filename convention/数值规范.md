# 战链DIY 数值规范（封闭语法 v1·2026-11-22）

> "数值"字段键封闭：距离/威力/速度/韧性（终结技为 α面/β面 各一组）。（2026-11-23：原"破点计数器"查无实卡出处，删除。）
> 值域语法如下，越界即录入错误（2026-11-22 用户拍板；双轨制延伸：存储层机器友好，印刷保真由展示层承担）。

## 一、存储层语法

| 形态 | 例 | 说明 |
|---|---|---|
| 整数 int | `5`、`-2` | 纯数字一律 int，符号入数值；风格修正值的"+"由展示层渲染 |
| 范围 str | `"1~3"`、`"-1~0"`、`"+0~2"` | 两端均可为负/带符号（风格修正范围合法，如卡琳咆哮 -1~0） |
| 变量 str | `"X"`、`"2X"`、`"+1~X"` | X 为卡面变量 |
| 无值 str | `"N/A"` | 印刷无此栏 |
| 特殊印刷 | `"护甲4"`（韧性栏）、`"<stun-shield>"`（韧性栏印眩晕免疫盾标） | 照录实卡 |
| 标签后缀 | `"6<initiative>"`、`"1~X<group-attack>"` | 符号一律用映射表字符串标签，禁存 ▲🛡👥 等图形字符 |
| 脚注后缀 | `"1~5*"` | 印刷星号脚注，含义入"效果" |

## 二、语义边界

- 修正值 vs 绝对值由"卡类"区分（风格/架势=修正值，基底/专属/终结技=绝对值），不靠字符串里的"+"号。
- **区间记法按语义分轨（2026-11-23 实卡例证钉死）**：数值栏/数值字段一律 `~`；规则文本内，移动关键词（前进/后退/移动/推动/拉动/逼近）引导的动作范围用 `-`（"前进或后退1-2"）；其余数值语义范围（距离替换、属性修正、等级等）用 `~`（"你的距离变为1~6*"，等同替换属性框数值）；排列序"1-2-3顺序"不动。
- 引擎解析：先剥 `<标签>` 与 `*` 后缀，再按 int / 范围 / X / N/A 求值。

## 三、展示层规则

- 风格/架势的四数值为修正值，展示层**一律强制带符号渲染**：正数"+N"、负数"-N"、零"+0"（2026-11-22 用户拍板）；基底/专属/终结技为绝对值，直出不补符号。
- `"N/A"` 栏位照常印刷"N/A"，不得留空或隐藏（2026-11-22 用户拍板：N/A 也要印）。
- `<initiative>`→▲、`<stun-shield>`→🛡、`<group-attack>`→👥；`*` 脚注星号原样保留。
