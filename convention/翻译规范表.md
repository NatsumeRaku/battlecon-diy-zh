# 翻译规范表（v1·2026-11-27）

> 合成源：《时点词表.md》（封闭时点）、《官方句对库.md》（9角色实卡平行语料）、《符号映射表.md》（标签语义）、2026-11-24~26 实卡规律登记。规则冲突时以规则书+三文件全文为准，本表是查询索引。
>
> **常条·裁定即时沉淀（行226用户裁定）**：用户对翻译/录入的每一处纠正，除用户声明的特例外，一律即时登记进本表（对应章节增行或改写旧行），并在修改表记行号；纠正先落卡面/规范，台账随后。

## 一、时点句式（时点字段值封闭，见《时点词表.md》）

| 英文 | 时点字段 | 效果行文前缀 | 标签 |
|---|---|---|---|
| Start | 开始 | 开始： | `<g-b>` |
| Reveal | 展示 | 展示： | `<b>`（黑粗） |
| Before / After | 前置 / 后置 | 前置： / 后置： | `<bl-b>` |
| Hit | 命中 | 命中： | `<r-b>` |
| Damage | 伤害 | 伤害： | `<r-b>` |
| End | 结束 | 结束： | `<g-b>` |
| Recycle | 循环 | 循环： | 照实卡（多为黑粗） |
| Ante / Limited Ante | 投注 / 限定投注 | 投注： / 限定投注： | `<o-b>` |
| Setup | 初始设置 | 初始设置： | 照实卡 |
| 常驻 | 持续 | 直书，零时点词 | 无 |

**当（Whenever/When）三条铁律**（行221用户裁定：字段值一律作"当"，"每当"是"当"的更限定行文变体，只留在效果照录层）：
1. 时点字段恒为 `当`，**必须带条件字段**，条件写完整触发句、含"当…时"（例：`你被命中时`）。
2. **字字精确**：效果字段按"当…时"印刷规律重写，即效果行文以 `当…时：` 开头照录原意（例：`当你被命中时:…`），不反向印"每当"；实卡原印"每当，…："的更限定变体（卡迦飞虫行成例）逐字照录不改。
3. **色粗前缀**：紫粗标签 `<p-b>` **只包"每当"二字**，条件与冒号留在标签外（行223用户裁定）：`<p-b>每当</p-b>你被命中时：你可以消耗 <i-sb>1 护盾</i-sb>…`；实卡未印"每当"的当条款用"当…时："式紫粗前缀。**禁止在"每当"后加逗号断句**（"每当，你被命中时："为行222登记误例，逗号仅在有插入从句时按实卡照录）。
4. **背景键**：当类条目必挂 `"背景": "灰底"`，投注类（投注/限定投注）必挂 `"背景": "橙底"`，值域封闭 `{灰底, 橙底}`（行223据卡背灰带/橙带实读确立）。

## 二、修正值与数字排版

| 规则 | 规范 | 例 |
|---|---|---|
| 修正值短语 | 整体入 `<i-sb>`，**逆序归一**：`威力+2`→`<i-sb>+2 威力</i-sb>`（±N 威力/速度/韧性/距离通用） | `<i-sb>+99 韧性</i-sb>` |
| 计数物/标记名 | 数字连名**整体入标签**，量词（面/个/枚/张）省略不入标签 | `你拥有 <i-sb>3 护盾</i-sb>。`、`消耗 <i-sb>1 飞虫</i-sb>`（行222登记） |
| 修正值短语不进 `<i-sb>` 的例外 | 已入 `<b>` 的护甲/削命短语不回溯 | `<b>护甲 2</b>` |
| 数字空格 | 数字与文字相连侧空一格，与标点相连侧省略；标签视为透明 | `每受到 1 点伤害`、`拉动 1-3。` |
| 范围 | 一律波浪号 `1~3` | 禁连字符当区间 |
| 风格数值 | 强制带符号 `+N/-N/+0` | 距离 `+2~4` |
| 基底/专属/终结技数值 | 绝对值直出 | 距离 1、威力 8 |
| N/A | 照常印刷，不隐藏 | 距离 N/A |

## 三、标记增减动词（封闭五词+资源动词）

| 场景 | 用词 | 禁 |
|---|---|---|
| 标记减少 | 回收 / 支付 / 消耗 / 使用 / 移除 | 自造 |
| 非标记资源（护甲/能量/生命） | 获得 / 生成 / 放置 | 与标记混用 |
| 计数必须实体化 | "每有 1 X"、"X+档位" | 台账式叙述 |
| 代价句式 | 支付 X 来 Y / 消耗其余所有 / 若你的 X 少于 N，则消耗尽可能多的 X | — |

## 四、移动词（封闭）

| 英文 | 中文 | 备注 |
|---|---|---|
| Advance | 前进 | 普适 |
| Retreat | 后退 | "尽可能后退"=Retreat as far as possible |
| 朝对手方向尽可能移动 | 逼近 | 雷克森肃成例 |
| Push / Pull | 推动 / 拉动 | 选择区间照录也用波浪号："推动或拉动 1~6"（行224登记，禁 1-6 连字符） |
| Teleport | 瞬移 | "瞬移至对手身后的任意格" |
| 随从标记位置变更 | 转移 | 不用"移动"："奥斯提朝对手转移 1 格（不可越过）" |

## 六、条件与选择句式

| 英文模式 | 官方中文 |
|---|---|
| If you cannot… | 若你无法做到（括号补充斜体：`(由于已经拥有所有诅咒)`） |
| Start, optional / Hit, optional | 开始，可选： / 命中，可选：（带距离作"命中，距离 N，可选："；**禁"（可选）"括号式**，"距离 1（可选）："为行224登记误例） |
| The opponent must choose and discard 1 base | 对手必须选择并弃置 1 张招式（实体牌量词"张"官译保留，数字入标签量词留外：`弃置 <i-sb>1</i-sb> 张招式`——行222量词省略以标记/计数物为限，行224登记） |
| If you advanced 2+ spaces and didn't move past the opponent | 若你因此移动了 2 或更多格并且没有移动越过对手 |
| For each X you have: +1 Speed | 每拥有 1 X 就 +1 速度 |
| If you have 3+ X | 拥有 3+ X（档位记法）/ 拥有 3 X（整数值条件式） |
| Whenever you would take more than X damage, change it to X | 每当你将要受到多于 1 伤害时，改为受到 1 伤害 |
| The opponent must choose and discard 1 base | 对手必须选择并弃置 1 张招式 |

## 八、段落级规则

1. **楷体描述段**（UA 技能说明段）：一切规则文本规律（时点句式/当…时/术语正字）不适用，逐字照录；仅允许 `<sb>` 标实卡半粗（`拜伦拥有 <sb>5 个假面</sb> 计数物`），`<i-sb>`/`<b>` 不入此段。
2. **状态牌括注**：卡文全段套 `<i>`，内嵌修正值/计数物照常 `<i-sb>`（`<i>` 可嵌 `<i-sb>`）。
3. **字色派生**：时点词字色为派生样式（开始=绿/命中=红/当=紫/投注=橙等），不单独存储；背景封闭值 `{灰底,橙底}`——"当"类灰底、"投注"类橙底。
4. **术语正字**：先查《中英译名对照表.md》；自筹术语须带"无官方先例+官方文本可覆写"双标签；译名冲突时以上级来源为准，下级标 [待核]。
