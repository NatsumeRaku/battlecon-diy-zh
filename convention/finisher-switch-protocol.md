# 变招风格/终结技·模拟唯一合法协议(最高优先级,用户终裁2026-11-21)

## 铁律
终结技**不存在"直接打出"**。唯一合法路径=变招风格(全员持有的风格牌)。任何模拟中终结技以普通牌身份进攻击组合/循环复用=**违规结算,该局作废重估**。

## 前置:双面卡
- 两面在同一张卡上;开局时双方**各自暗地选好一面,同时展示**。
- 此后**除非卡牌效果,终结技不能自行翻面**——暗选本身是博弈一环。

## 变招风格的两种用法(用户终裁原文)

**方法一·宣言打出(主效果)**:
展示宣言 → 付**手持能量=当前生命** → 终结技替换整个攻击组合(不吃风格/招式修正,完整边框独立结算) → **变招风格永久移出游戏**,基础招式捡回 → **此时不结算结束效果** → 跳过常规循环 → 消耗"每局1次终结技"额度。终结技本体不进循环不进手牌,只在场上等待。

**方法二·不宣言(从属效果)**:
展示时可**不选择移除能量**(如发现大招开了也没法命中),则整条展示跳过 → **结束效果照结算**:回1点能量+可把终结技卡翻到另一面 → 变招风格和招式**正常进入循环**。即变招风格可当"1能量+翻面"引擎用(占用风格位,两回合循环一次)——这是feature不是漏洞。

## P1-P4终裁
1. **移出的一直是变招风格**;终结技不进入循环/手牌,只在场上等待替换窗口。旧文本"终结技移出游戏"作废。
2. 不付能量=展示整条跳过,结束效果照送。
3. 支付来源=**手持能量**(上限10):生命>10物理不可付——这是使用时机硬性锁,同时构成信息博弈(对手见你攒能量=预告终结技)。
4. **翻面不限次数**,只要能翻(每循环一次变招风格)可以一直翻。

## 历史错误忏悔(防再犯)
2026-11-21之前所有涉及终结技的模拟(数百场)均按"终结技=可循环普通牌"结算,双重违规:
- 未走变招风格流程(未付生命等值能量、未移出风格);
- 多次使用(违反每局1次)。
受影响最深:愚者(穿心/万箭)、卢克(抹除者/苍白骑士)、春丽(苍天乱华)、杰米(月牙)、储君(陨星)——其核心胜场建立在违规结算上,评分待闸门重估。
**唯一豁免说明**:观者"神格21" mostly=UA神格架势(投注3奇迹,专属机制层,合法 repeatable),非终结技面板——该类结算有效,但神格终结技面板的额外射击虚增威慑。
电池六十六(闸门修正复测)部分场次仍按旧口径打出终结技(如卢克抹除者当普通牌),**该电池结果全部标注污染**,待本协议重跑。

## 死亡时点裁定(N17,用户2026-11-21)
**生命归零,决斗立即结束——同回合后手方待结算的攻击与全部命中触发一并吞掉**(含回收/吸血/削命返还能回血的效果):能回血的死人也是死人。死亡判定优先于一切待结算队列。

## 模拟执行清单(每场必查)
- [ ] 该角色本局终结技是否唯一1次、是否走了变招宣言+付费+风格移出?
- [ ] 终结技回合是否跳过常规循环、替换整个组合(风格/招式修正不叠加)?
- [ ] 支付是否≤手持能量(≤10)且=当前生命?
- [ ] 翻面只经方法二,且记录已用额度不受翻面影响?
- [ ] 生命归零即终局:待结算攻击/触发全部作废?
