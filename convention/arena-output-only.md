# 竞技场边界公约:只出建议,不动文件

## 规则
1. 竞技场(本对话及其后续会话)**只**做:对局模拟、战报撰写、克制链分析、平衡补丁建议(含具体改法文本)、裁决意见汇总。
2. **禁止**在本会话直接修改任何角色设计文件(diy-*.md)、术语表、规则书载录、战报库(sim-report)以外的文件。
3. 平衡补丁经用户拍板后,由用户在专门的改卡对话(战链DIY修改室)落地;竞技场只负责把"建议改法"写成可直接照抄的文本。
4. 战报库 sim-report-diy-roundrobin.md 属竞技场本职产出,可正常追加电池记录;但其中若涉及"已拍板待落地"的补丁状态,只标注状态,不代改角色文件。
5. 若用户在本会话要求"直接改",回显本公约并引导至改卡对话。

## 理由
用户2026-11-20原话:"以后只你输出建议,不在你这里改,避免同时施工导致出错"——多会话并行(翻译校正室/竞技场/DIY修改室)时防止版本冲突。
