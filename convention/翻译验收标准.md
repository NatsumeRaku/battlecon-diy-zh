# 机器翻译辅助录入验收标准（2026-11-27 行240 定案）

适用：本地 LLM（llama.cpp Qwen 系）批量初译卡面效果，人工/规则验收后入 zh 树。

## 一、三硬指标（全部归零才准入库）

| 指标 | 判法 | 容忍 |
|---|---|---|
| 英文术语残留 | 效果正文出现效果词表英文词（Power/Priority/Range/Guard/Armor/Stun/Advance/Retreat/Push/Pull/Hit/Reveal/End/Before/After…按词表全列） | 0 |
| 时点词误用/残留 | 时点位只用八词：展示/开始/前置/命中/伤害/后置/结束/循环；英文时点词残留同罚 | 0 |
| 数字保真 | 原文每个数字串（含 1~3、0-X）须在译文中可找回（~ 与 - 互通） | 0 |

辅助检查（不卡入库但需人工抽看）：元话语污染（"翻译：/解释：/注："）、角色名音译漂移。

## 二、术语硬表（来源：convention/中英译名对照表+官方句对库，冲突以上级为准）

威力=Power（禁"力量"）；速度=Priority（禁"优先级/先攻"，▲标记除外按卡面）；距离=Range（禁"范围"）；韧性=Guard（禁"防御/防护"）；护甲=Armor（禁"装甲"）；眩晕免疫=Stun Immunity；格=space（禁"空间/格子"混用，计数实体化）；推动=Push/拉动=Pull；前进=Advance/后退=Retreat；命中=Hit；展示=Reveal。

## 三、流程

1. en 树原文 → 本地模型初译（系统提示词 = 时点词表+官方句对库+中英译名对照表，**克制喂入**：对照表摘要级即可，全文灌入会导致术语回退与元话语污染——v3 教训）
2. 规则脚本跑三硬指标 → 定点修复（修复键用 en 子串匹配，**禁用 en[:20] 硬切**——已踩键错位坑）
3. 抽样三方对照（en/v2/final）交用户终审
4. 终审通过后入 zh 树，入树格式按 json-db/zh 成熟先例（时点展示层中文、效果中文、数值字符串带符号）
