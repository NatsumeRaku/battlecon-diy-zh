# 竞技场会话强制开局流程(用户2026-11-21逐字收录,最高行为优先级)

**每次会话跑分/裁定前**,先完整阅读项目记忆文件 **arena-rules-brief.md**(战链规则精读·竞技场必读)与 **battlecon-glossary.md**(钦定术语表),并遵守:

1. 一切裁定以 arena-rules-brief.md 第十一节自查清单逐条过;**规则适用顺序(2026-11-22立宪·以规则书为最高准则):①中文规则书v4.2(battlecon-rulebook.md官方中文主档+rulebook-cn-a/b/c) ②模式指南 ③英文规则书 ④用户口述;例外:用户以"规则书是这么说的"裁决时视同规则书原文,列最高**。
2. 不确定的规则不许即兴发明——在战报中标注**【待核】**并继续,不要编造数值/时点/效果。
3. 每场战报末尾附**"本场所用裁定"栏**:列出本场所有非显而易见的规则应用点(眩晕/护甲/时点/距离各至少自查一次)。
4. 角色数据以名册文件为准;缺失数据注明缺口,**禁止拟合**。
5. 术语一律用钦定表译名(含"赛博·"前缀与DIY角色名)。
6. 多角色机制冲突时,先按完整信息公开原则推演双方最优,再写战报。

## 配套已生效裁定(与本流程同档)
- 终结技唯一路径=变招风格(见 convention/finisher-switch-protocol.md):宣言付手持能量=当前生命/风格移出/每局1次;不宣言则展示跳过、结束回1能量可翻面;翻面不限次;开局暗选面同时展示。
- 死亡时点(N17):生命归零立即终局,同回合待结算攻击与命中触发(含回血)全部作废。
- 位移:同格永不可;前进可越过(跳过不占格数),逼近不越过;移动方向距离在声明时定死一次性走完。
- 同速Clash=双方暗置新招式盖上重比(风格不动),非"双方无效";▲免冲突且胜。
- 削命无主语=对手;自伤写"受到削命X"。
- 眩晕:本回合累计伤害>韧性才晕(等于不晕,每回合独立清零);眩晕只跳过前置/命中/伤害/后置,开始/结束/循环照走,回合末自动结束;眩晕免疫(盾)≠无限韧性,后者被自动眩晕击穿。
- 护甲写在效果栏,回合结束过期不攒;减伤=威力-护甲最低0。
- 通用六招数值以 arena-rules-brief.md 第一节所引规则书原文为准(猛冲1/3/4,射击1~4/3/2/韧2,强袭1/4/3/韧5,抓投1/2/5,轰击2~3/3/1,闪避N/A/N/A/3/0)。
