# 配件条目规范（2026-11-24 新增）

## 一、定位

"配件"为卡类封闭值新增项，用于录入斗士随盒附带的指示物／计数物／标记等实体配件。一张配件一个 JSON 文件，置于所属角色目录下，命名 `配件_<名称>.json`。

## 二、字段（八字段之外的新增字段）

| 键 | 类型 | 值域 | 说明 |
|---|---|---|---|
| 角色 | string | 同目录角色名 | |
| 名称 | string | 配件印刷名 | |
| 卡类 | string | 固定 `配件` | 卡类封闭值新增 |
| 系列 | string | 系列封闭值 | |
| 类别 | string | `指示物`／`计数物`／`标记` 三选一（封闭） | 由实物形状反推（见三） |
| 效果 | string | 仅 `指示物` 非空；其余类别固定空字符串 | 逐字转写配件卡上的效果文本 |
| 数量 | int | 正整数 | 以 UA 卡／角色卡上的数量提示为准；无提示时按实物枚数录入并标 [轻待核] |
| 形状 | string | `圆形`／`五边形`／`正方形` 三选一（封闭） | 由类别映射（见三），不直接录实物形状 |
| 来源 | string | 四值封闭 | 同《来源值域.md》 |
| 备注 | string | 自由 | 实物形状与映射不一致、数量无提示等均在此标注 [轻待核] |

## 三、类别—形状映射（反推规则）

- 实物为圆形／球体 token → `指示物`，形状 `圆形`，效果非空。
- 实物为五边形计数 token → `计数物`，形状一律记 `五边形`，效果空。
- 实物为方形小片／方块卡 → `标记`，形状 `正方形`，效果空。

**命名区分准则（2026-11-24 用户指正，以 UA 文本命名为最高准）**：UA 卡写作“××计数物”的（如卡迦“7 个飞虫计数物”）→ `计数物`；UA 卡写作“××标记物”的（如沃客“丧尸标记物”、楷“凝胶标记物”、玛格莉娜“英灵标记物”）→ `标记`，形状 `正方形`，不受计数物五边形准则约束。两类不混用。

反推优先级：UA 卡／角色卡文字中的类别命名为最高准（如"威胁计数物"直接定 `计数物`）；实物形状仅作辅助。实物形状与映射值不一致时（如六边形 tile 映射为五边形），在 `备注` 记 `[轻待核]`，不改映射值。

## 四、数量提示识别

UA 卡（卡类=特技(UA)）常带"塞萨尔拥有 5 个威胁计数物"式提示，数量取该提示值；提示缺失时按实物枚数录入并标 [轻待核]。

## 五、en 树规则

en 树遵循既有 en 树约定：文件名与名称维持中文，英文内容仅入"效果"（逐字录官方英文）与"备注"；类别映射：指示物=Token／计数物=Counter／标记=Marker；形状：圆形=Circle／五边形=Pentagon／正方形=Square。英文配件名无官方卡面时按对照表译名并标 [轻待核]。

## 六、生效登记

本规范经《战链json-db标准化修改表》2026-11-24 行 118 登记生效；首例录入：毁灭篇-DEV 塞萨尔·格里斯特之"威胁"。首例"不可避免"经复核为状态效果牌缩略图，非配件，已撤录（行120）。

## 计数物形状准则（2026-11-24 用户裁定，登记为准则）

计数物一律为五边形，不存在六边形配件；录入时计数物“形状”字段固定填“五边形”。（用户裁定：没有六边形配件，计数物都是五边形。）注意：本准则只约束 `计数物`；`标记`（UA 称“××标记物”）仍为方形小片，记 `正方形`。
