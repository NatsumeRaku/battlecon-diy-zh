# 官方字体与色值规范（官方口径·2026-11-27 用户提供）

> 用途：①DIY 制图直接照排；②字体暴力匹配管线的渲染参数；③时点词字色派生样式的官方依据。

## 一、字体字号

| 版面位置 | 字体 | 字号 |
|---|---|---|
| 卡名 Card Names | AngryBlue | 72pt（通常） |
| 角色名 Character Name | Copperplate | 57pt |
| 角色副题 Character Subtitle | Copperplate Light | 30pt |
| UA 名 UA Name | Copperplate Light | 36pt |
| 参考牌标题 Refcard Title | Copperplate Light | 64pt |
| 数字 Numbers | Charlemagne Std Bold | 96pt |
| 其余全部正文 | Times | 28pt（通常） |

- 本地已有（`memory-pending/fonts/`，行250网络搜集入库）：`ANGRYBLU.TTF`（用户官方验证）、`Copperplate.ttf`、`Copperplate Bold.ttf`、`Copperplate Gothic Light.ttf`、`CharlemagneStd-Bold.otf`；Times 用系统自带。
- **许可注意**：Copperplate/Charlemagne 系商业字体（Adobe/Monotype 等权属方），网络拷贝仅供本项目本地匹配比对学习用，不得商用、不得随项目对外分发；商用制图请购买正版授权。
- 卡名暴力匹配管线参数：AngryBlue 72pt 超采样渲染 + 二值化 + chamfer 双向比对（行241 PLANE DUDER 定案成例）；UA 名 Copperplate Light 36pt、数字 Charlemagne Std Bold 96pt 同款流程可用（行250字体到位）。

## 二、时点词字色（官方色值）

| 时点组 | HSV | RGB | hex |
|---|---|---|---|
| SoB / EoB（开始/结束） | 120-100-50 | 0-128-0 | 008000 |
| BA / AA（前置/后置） | 240-100-80 | 0-0-204 | 0000cc |
| OH / OD（命中/伤害） | 0-100-70 | 179-0-0 | b30000 |
| 其余全部 | 黑 | 0-0-0 | 000000 |

- 与库内派生样式互证：开始/结束=绿、前置/后置=蓝、命中/伤害=红（翻译规范表八.3"字色派生"的官方依据）。
- 展示=黑粗、当=紫、投注=橙，本规格未列（非"其余"组时按实卡照排）。
