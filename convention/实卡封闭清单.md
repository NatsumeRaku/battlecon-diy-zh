# 实卡封闭清单(2026-11-24 建立)

## 规则
- DIY-工坊vN 是自制打印卡,**不构成实卡凭证**,任何目录不得凭 DIY 来源申请封闭;DIY 卡的录入标准向实卡看齐(时点句式、术语、角标语义、内联标签同规范)。
- 下列角色目录的存量 JSON 已经实卡凭证录入(用户拍照/上传样张/英文实卡译文),**封闭**:
- 任何批量清扫(内联标签、数字空格、正字展开、句式归一、标点归一)一律跳过这些目录;
- 仅两种改动允许:①用户当次指令的定向修改;②新增文件(如补拍卡、状态牌),新文件须当场按现行规范录入;
- 解封须用户明示。封闭不改变"来源"字段登记义务。

## 官方中文覆盖口径(2026-11-25 登记)
- 依据:Level 99 Games 官方 Discord 社区管理员 TheMechanicritic 答复(2026-11-25,Natsume Raku 询问媒体素材时确认:"只有 DEV 有中文卡"),结合用户实卡收藏核实。
- **斗士牌(角色专属牌:UA/风格/专属/终结技)的官方中文仅毁灭篇-DEV**;BCD 之外各系列(BCW/BCT/BCF/SOLO 等)的斗士牌无官方中文,现存中文文本均属 DIY/社区译文,来源字段不得标"官方实卡"。
- **例外:通用牌类**——通用招式牌、竞技场牌、终极/超级类牌,DEV 之外亦有官方中文实卡,不受上条限制,凭证以实拍/官网图为准。
- 本条仅约束"来源"字段与封闭申请口径,不否定既有英文照录条目。
