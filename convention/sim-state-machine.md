# 对局模拟状态机协议(用户2026-11-21裁定,最高行为优先级)

## 铁律
凡指令涉及"跑对局/跑循环赛/跑测试/跑X vs Y",**一律用 ipython 写可执行代码运行真实状态机**,禁止用叙事推演拟合比分。此前所有"比分/B数/剩余生命"类输出均为低置信示意,本协议生效后不再单独生成此类数字。

## 执行标准
1. **状态完整性**:生命/能量/站位/代币/手牌/弃牌/移出游戏 全部入状态;回合推进=纯函数转移。
2. **规则断言**:每回合自检不变量——血量守恒(削命不致死最低1)/能量守恒/代币守恒/手牌守恒/距离合法/时点顺序(展示<前置<开始<速度<命中<伤害<结束<循环)/同格永不可/护甲回末过期/眩晕每回合独立判定。
3. **reconcile**:每场结束校验"Σ伤害=生命差",不过不放行。
4. **策略**:双方用策略函数(启发式评估+合法走法枚举);对抗不确定处用蒙特卡洛多样本,输出**胜率+置信区间**,不输出单场比分。
5. **隐藏信息**:攻击组合暗置——模拟用同时行动+公开信息集,不偷看对方选择后再决策。
6. **裁定源**:规则执行以 arena-rules-brief/规则书/用户裁定为准;不确定标【待核】,禁止即兴发明。
7. **输出形态**:战报只写"结构结论+统计+关键规则应用",每场末尾附"本场所用裁定"栏(沿用六规则第3条)。

## 实施路线(分阶段,用户不缺时间)
- 阶段1:核心回合引擎(投注/展示/移动/速度/命中/伤害/眩晕/结束/循环)+两名角色数据化,用手算过的对局(亚历克希安vs雷克森前7回合)做回归校验。
- 阶段2:录入现役角色卡池(DIY+必要的官方标杆),策略函数=评估函数+合法集。
- 阶段3:批量对局,输出胜率矩阵与置信区间,替换旧评分表的示意数字。
- 全程:名册数据缺失处标缺口,禁止拟合(六规则第4条)。
