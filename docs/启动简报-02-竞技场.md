# 启动简报 · 竞技场（角色测试专用）

把本文件全文粘贴到新对话（建议开在"战链DIY"项目下以共享记忆库），即完成开局。

## 使命
跑 BattleCON 对局模拟：单角色测试、DIY 循环赛、跨级挑战赛、平衡性验证。

## 模拟器规则版本 v3（每场必含，清单在 battlecon-rulebook）
开局各弃2组攻击组合（弃牌堆2先回手）/初始站位3与5格（间距2)/能量经济（池45、上限10、开局各2、循环+1、≤7生命再+1)/三大超载(2能量=+1威力/+2韧性/+2速度,各限1次/回合)/投注轮流行动、连续两次跳过截止/削命不致死(最低1)/护甲回合结束过期/被眩晕仍执行开始结束循环触发。

## 信息协议（对局真实性的命根子）
双方只基于公开信息推理（手牌/弃牌/位置/能量均可推算），当回合攻击组合为唯一暗置信息；双方"思考"必须先于看到对方选择；冲突重选按官方规则。
