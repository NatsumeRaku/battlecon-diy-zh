## 特殊能力·充能球槽
- 你有3个充能球槽与充能球供给区:闪电×2、霜冻×2(每型2枚=该型终身供给,消耗区不可回收)。
- 初始设置:将所有充能球放在供给区。生成1闪电球,1冰霜球。
- 开始:结算每个充能球槽中充能球的效果。
- 生成:将供给区1充能球放入充能球槽。若无法做到,先激发1充能球。
- 激发:结算对应效果两次,消耗该充能球。
- 限定投注:激发1个球。
- 集中:你的闪电球效果获得削命X,冰霜球效果获得护甲X,X=你的集中数(至多3,开局0)。
- 闪电球效果:削命1。冰霜球效果:护甲2。
- 【等离子标记:之后做成提示卡,暂存于流星撞击卡面】
