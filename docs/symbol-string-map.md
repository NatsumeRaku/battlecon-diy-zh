# 战链卡面符号→字符串映射全表+双轨渲染规则(v2·2026-11-21执行版)

> **双轨制(用户2026-11-21裁定,全项目生效)**:
> - **存储层**(记忆文件/转录原文):一律写字符串标签,如`<g-bold>`、`<blue-circle>`、`<b-i>1假面</b-i>`
> - **展示层**(对用户的任何输出:回复/引述/交付文件):按本表反向渲染为符号与中文尖括号,如⟨绿粗⟩、●、***1假面***

## 四、文本格式标签(9项)

| 字符串(存储) | 渲染(展示) | 用途 |
|---|---|---|
| `<g-bold>…</g-bold>` | ⟨绿粗⟩…⟨/⟩ | 开始/结束 |
| `<r-bold>…</r-bold>` | ⟨红粗⟩…⟨/⟩ | 命中/伤害 |
| `<k-bold>…</k-bold>` | ⟨黑粗⟩…⟨/⟩ | 展示/循环/初始设置 |
| `<b-bold>…</b-bold>` | ⟨蓝粗⟩…⟨/⟩ | 前置/后置 |
| `<p-bold>…</p-bold>` | ⟨紫粗⟩…⟨/⟩ | 即时触发词 |
| `<o-bold-beige>…</o-bold-beige>` | ⟨橙粗米底⟩…⟨/⟩ | 投注条款 |
| `<gray-bg>…</gray-bg>` | ⟨灰底⟩…⟨/⟩ | 即时整句底 |
| `<simsun>…</simsun>` / `<simsun-small>…</simsun-small>` | ⟨宋体⟩…⟨/⟩ / ⟨小宋⟩…⟨/⟩ | 概述/风味 |
| `<b-i>…</b-i>` | ***…***(加粗斜体) | +X威速韧/X计数物/无视X |

## 五、复用规则
1. 效果来源标注复用角标词表(来源=红菱风格→`<red-diamond>`);无明确来源不得滥用
2. 中文旧标签与markdown加粗斜体已按表替换完毕(2026-11-21),不留双轨
3. 渲染为全项目默认;交付第三方时视接收方定渲染版或字符串版
